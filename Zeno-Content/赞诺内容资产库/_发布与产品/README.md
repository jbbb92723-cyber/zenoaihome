# _发布与产品/ 索引

> 这是市场输出与交付中台，不是知识真源。
> 网站文章生效正本在 `../../../Zeno-Code/zeno-site/data/content/`，内容草稿在 `../内容结构化系统/06-选题装配/`。

## 在整个系统中的位置

```text
内容结构化系统的内容单元 / 案例 / 方法候选
  → 产品与发布包
  → 人工审核与平台发布
  → 用户反馈、咨询、采用或拒绝
  → 回到项目记录与内容结构化系统复盘
```

发布成功不等于观点已验证，产品页存在也不等于服务已经上线。状态要以各自的 `publish.yaml`、项目记录和网站代码为准。

## 归属规则

- 产品页保存交付承诺、适用对象、边界和当前状态；方法论本体回到内容结构化系统。
- 发布包保存平台表达和发布状态；不要把平台改写稿当作内容单元主版本。
- 反馈保存具体原话、行动和结果；只有经过判断的可复用部分才回流为案例、观点或方法。
- 旧的 `G:/...` 路径只保留为历史记录，不作为当前操作入口。
