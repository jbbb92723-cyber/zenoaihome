# ZENO赞诺企业 Logo 使用说明

## 品牌关系

- `ZENO赞诺`：企业母标，同时承接赞诺个人 IP 的外部识别。
- `广西赞诺数智科技有限公司`：签约、收款、企业服务和赛事协办的法定主体。
- `星火者创业实践共同体`：独立子品牌，不替代公司出现在正式协办单位栏。

## 设计逻辑

主标延续 ZenoAIHome 网站的炭黑、骨纸和朱砂体系。现代黑体保证赛事 Logo 墙和网站导航中的识别效率；`O` 保留一道受控开口，并由唯一的朱砂笔画闭合，表达持续实践与人的判断责任。

品牌名称固定写作 `ZENO赞诺`。不写成 `Zeno 赞诺`、`Zeno赞诺`、`赞诺Zeno` 或 `ZENO AI`。

## 文件选择

| 场景 | 使用文件 |
|---|---|
| 华为云赛事协办单位 | `ZENO赞诺-协办单位-彩色.svg` 或透明底 PNG |
| 赛事要求纯黑 Logo | `ZENO赞诺-协办单位-单色.svg` |
| 深色背景 | `ZENO赞诺-协办单位-反白.svg` |
| 网站导航、个人海报 | `ZENO赞诺-网站导航.svg` 或 `ZENO赞诺-主标-彩色.svg` |
| 头像、favicon、极小图标 | `ZENO赞诺-O印记.svg`，不得代替正式机构署名 |

数字场景中，带公司全称的机构版建议不小于 `240px` 宽；展示位更小时改用不带公司全称的主标，并由赛事页面的单位名称字段标注法定主体。完整主标建议不小于 `120px` 宽，辅助 O 印记建议不小于 `24px`。

## 网址规则

Logo 本体不加入网址。支持链接的页面，应将 Logo 直接链接到 `https://zenoaihome.com`；海报、公众号和线下物料可在独立信息区放网址或二维码。

## 色彩

- 炭黑：`#111111`
- 骨纸：`#F4F1E8`
- 朱砂：`#9E2B25`

朱砂只用于 `O` 的判断笔画，不扩大为大面积装饰。

## 网站接入

网站导航使用 `ZENO赞诺-网站导航.svg`，不显示公司全称。当前网站代码仍有 `Zeno 赞诺` 的历史写法，正式接入 Logo 时应统一为 `ZENO赞诺`，但不改变网站“个人博客与公开实践档案”的主体定位。

## 禁止

- 不拉伸、压扁或改变字标比例。
- 不把公司全称和网址同时塞进 Logo。
- 不给 Logo 增加阴影、渐变、发光或圆角底牌。
- 不在协办单位栏用头像、星火者 Logo 或 `ZenoAIHome.com` 文字替代企业母标。
