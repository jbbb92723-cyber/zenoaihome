# OPC 白皮书专题资产

> 这里是 OPC 主题的研究原件、长文、政策材料和对外交付包。它是专题资产区，不是全库唯一知识真源。

## 内容分层

| 层级 | 典型内容 | 使用规则 |
|---|---|---|
| 外部原件 | 政策、研究报告、书籍和行业材料 | 保留作者、出处、日期和版本 |
| 作者解读 | 赞诺对政策、行业和实践的解释 | 标明哪些是事实、哪些是判断、哪些待验证 |
| 实战框架 | 可执行的诊断、清单和行动手册 | 进入真实项目或用户试用后再升级证据状态 |
| 交付排版 | PDF、发布版和视觉派生物 | 属于输出副本，不覆盖 Markdown 或来源事实 |

## 与内容结构化系统的关系

需要长期复用的概念、观点、案例或方案，单独登记来源后，交给 `../../内容结构化系统/` 加工。不要把整本 PDF 直接当成一个观点单元，也不要把外部研究数字直接当成赞诺案例。

## 当前入口

- 研究与长文原件：本目录顶层文件
- 历史排版与旧版：`归档/`
- PDF 生成工具：`opc-pdf-publisher/`，只作工具，不是方法论真源
