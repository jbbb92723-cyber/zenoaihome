## 第一章：OPC到底是什么

### 1.1 一句话定义

**OPC（One Person Company），一人公司。**

不是"一个人的小生意"。是以一个人为核心，借助AI工具和外包协作，实现团队级产出的新型创业形态。

### 1.2 OPC 和传统创业的本质区别

| | 传统创业 | OPC 一人公司 |
|---|---------|------------|
| **核心逻辑** | 招人 → 分工 → 规模化 | 单人+AI → 外包 → 利润最大化 |
| **成本结构** | 房租+工资+管理成本高 | 几乎零固定成本 |
| **决策速度** | 慢（需要开会、审批） | 快（一个人拍板） |
| **风险** | 高（投入大、退出难） | 低（轻资产、可快速试错） |
| **天花板** | 高（可规模化） | 中（受限于个人精力） |
| **适合人群** | 有资金、想做大 | 有技能、想自由 |

### 1.3 OPC 适合谁

- 有专业技能但不想打工的人
- 传统行业想转型但不想重资产投入的人
- 已经在做自由职业，想升级成公司化运营的人
- 想借助AI放大个人产能的人
- 想利用南宁东盟区位优势做跨境业务的人

## 第三章：注册指南——一个人怎么合法开公司

### 3.1 三种注册形式怎么选

| 形式 | 优点 | 缺点 | 适合 |
|------|------|------|------|
| **个体工商户** | 注册快、成本低、税简单 | 无限责任、不能开专票 | 收入稳定、风险低的自由职业 |
| **个人独资企业** | 一人所有、税负较低 | 无限责任 | 小型工作室 |
| **有限责任公司** | 有限责任、可开专票、正规 | 注册稍复杂、有记账要求 | 想做B端业务、需要签合同的 |

> **建议**：一开始用个体工商户起步。需要签B端合同、开增值税专用发票时，再升级为有限责任公司。

### 3.2 注册流程（以有限责任公司为例）

**第一步：核名**
- 在广西企业登记服务平台提交3-5个备选名称
- 格式：南宁+字号+行业+有限公司
- 例：南宁赞诺数智科技有限公司

**第二步：准备材料**
- 法人身份证
- 注册地址证明（可用社区工位地址）
- 经营范围（建议尽可能写宽，方便后续扩展）
- 注册资本（认缴制，无需实缴）

**第三步：线上提交**
- 广西政务服务网 → 企业开办一网通办
- 同步完成：营业执照 + 刻章 + 税务登记 + 社保开户

**第四步：刻章 & 银行开户**
- 公章、财务章、法人章（社区一般有合作刻章点）
- 开对公账户（推荐招商银行、桂林银行，对初创友好）

**时间预估**：3-5个工作日拿营业执照，全程线上可完成。

### 3.3 注册地址怎么解决

- **社区工位**：十个OPC社区均提供注册地址，部分免租或低价
- **集群注册**：南宁支持集群注册，一个地址可注册多家公司
- **自用住宅**：符合条件的住宅可注册（需居委会证明）

### 3.4 经营范围怎么写

> 建议尽可能写宽。以下是一个参考模板：

```
软件开发；人工智能应用开发；人工智能行业应用系统集成服务；
信息系统集成服务；智能控制系统集成；信息技术咨询服务；
数字技术服务；大数据服务；物联网技术服务；
技术进出口；企业管理咨询；教育咨询服务（不含涉许可审批的教育培训活动）；
业务培训（不含教育培训、职业技能培训等需取得许可的培训）；
数字内容制作服务（不含出版发行）；广告设计、代理；
广告制作；品牌管理；市场营销策划；会议及展览服务；
组织文化艺术交流活动；专业设计服务；
工程管理服务；互联网销售（除销售需要许可的商品）。
```

## 第四章：财税基础——不被税务局找麻烦

### 4.1 税种速览

| 税种 | 小规模纳税人 | 一般纳税人 |
|------|------------|-----------|
| **增值税** | 1%（月收入10万以下免征） | 6%/13% |
| **企业所得税** | 利润的5%（小微企业优惠） | 利润的25% |
| **个人所得税** | 分红时20% | 分红时20% |

> **重点**：小规模纳税人月收入10万以下，增值税全免。大部分OPC创业者在初期都享受这个政策。

### 4.2 发票怎么开

- **电子发票**：在电子税务局申领，自己开
- **找代理**：200-300元/月，有人帮你记账报税
- **UKey**：税务局免费申领税控设备

### 4.3 记账：自己做还是找代理

- **自己做**：用「慧算账」「云帐房」等工具，免费版够用
- **找代理**：200-500元/月，省心但要注意找正规的
- **建议**：初期自己记（收入少、账简单），业务多了再交给代理

### 4.4 成本抵扣

- 社区工位租金
- AI工具订阅费（ChatGPT、Claude、Midjourney等）
- 外包服务费
- 差旅费
- 培训学习费
- 设备折旧

## 第五章：运营实战——一个人怎么跑起来

### 5.1 定价方法论

**不要按小时定价，按结果定价。**

| 收费模式 | 适用场景 | 定价参考 |
|---------|---------|---------|
| **按项目** | 明确交付物的服务 | ¥3,000-30,000/项目 |
| **按月费** | 持续服务（顾问、代运营） | ¥2,000-10,000/月 |
| **按效果** | 能直接量化的服务 | 收入的10-30%分成 |
| **产品化** | 标准化数字产品 | ¥99-999/份 |

> **一个实用的定价公式**：  
> 你的年收入目标 ÷ 12 = 月收入目标  
> 月收入目标 ÷ 你能同时服务的客户数 = 单个客户最低收费  
> 例：目标年入24万 → 月入2万 → 同时服务5个客户 → 每个客户至少¥4,000/月

### 5.2 获客：从0到第一个付费客户

**第一层：免费的信任资产**
- 写你擅长的东西（公众号、知乎、小红书）
- 在你所在的OPC社区做分享
- 帮人免费解决一个小问题，积累口碑

**第二层：低价的钩子产品**
- 定价¥99-199的轻咨询/诊断/报告
- 目的不是赚钱，是让客户体验你的价值

**第三层：核心服务**
- 你的主力收费产品
- 客户从钩子产品升级而来

### 5.3 一个人怎么看起来像一个团队

- **合同**：用「腾讯电子签」「法大大」电子合同
- **收款**：微信/支付宝商户 + 对公账户
- **沟通**：飞书/企业微信，显得正式
- **交付**：Notion/飞书文档作为交付物载体
- **AI助理**：用AI做客服回复、文案润色、数据分析

## 第八章：常见问题

**Q：没有营业执照可以做OPC吗？**

可以。自由职业阶段不需要注册。但要做B端业务、签合同、开发票，建议尽早注册。

**Q：注册公司后是不是每个月都要报税？**

是的。即使没有收入也要零申报。不报税会有罚款和信用记录影响。

**Q：OPC社区免租是真的吗？**

部分社区提供免租期（3-6个月不等），之后收取低价的工位费（200-800元/月）。具体咨询各社区。

**Q：一个人能做跨境电商吗？**

能。利用AI翻译、AI选品、AI客服，一个人做跨境的门槛已经大幅降低。南宁还有面向东盟的地理优势。

**Q：我需要会编程才能用AI吗？**

不需要。现在大部分AI工具都是对话式的，会用微信就会用AI。

**Q：OPC能赚到钱吗？**

能。但前提是：你有一项别人愿意付费的技能 + 你知道怎么让需要你的人找到你。这份白皮书里讲的获客和定价方法，就是帮你解决后半段的问题。
