# 政策解读

## 南宁市AI OPC先行区支持措施（15条）

2026年7月，南宁市正式发布人工智能OPC创业先行区15条支持措施。

### 核心补贴

- **算力补贴**：入驻AI社区的一人公司，每年最高可获5万元算力券
- **场地补贴**：前6个月免租，后6个月减半
- **人才补贴**：邕江计划入选者最高50万元创业资金
- **贴息贷款**：最高30万元，年利率3%补贴

### 申报流程

1. 社区入驻确认
2. 提交AI业务证明材料
3. 高新区/良庆区科技局初审
4. 市科技局复审（15个工作日内）

## 中国-东盟博览会创业机会

2026年第23届东博会将于9月在南宁举办，OPC创业者可关注：

- **东盟企业对接会**：100+东盟企业寻求AI合作伙伴
- **OPC创业专区**：首次设立，面向一人公司
- **跨境电商政策**：展示期免签证、绿色通道

> 💡 **建议**：有出海意向的OPC提前注册，东博会官网6月已开放报名。
