# START｜今日入口

## 先问五个问题

1. 这份资料属于谁的经验？
2. 它服务哪个角色？
3. 这个角色正在完成什么目标？
4. 它解决什么真实问题，需要什么技能？
5. 它应沉淀为事实证据、案例、观点、方法、工具还是产品？

完整的外层分工见 [`资产库业务地图.md`](资产库业务地图.md)。如果资料已经明确是文稿、选题、案例或课程稿，再进入 dbskill 内容工程；不要把所有资料直接塞进内容结构化系统。

## 当前优先级

1. 以 `OPC 公开实践者` 为主角色，收集 3 份真实签约前报价问题，选 1 份完成最小审核。
2. 留下脱敏输入、判断过程、用户复述和适用边界，不先把方法写成已验证。
3. 围绕同一个真实问题形成视频、公众号和网站的一题多端内容包。
4. 让 1 位星火者或目标用户试用工具并回填反馈。
5. 将经验证据回流内容单元、方法卡和网站，建立可核验的信任。

## 最短工作闭环

```text
选一个角色
→ 定一个 30～90 天结果
→ 收一个真实问题
→ 做一个最小实践
→ 留下证据和资产
→ 再交给内容结构化系统加工
→ 发布 / 服务 / 星火者试用
→ 回填反馈与复盘
```

## 不做

- 不为了整理而整理。
- 不建新的平行知识库。
- 不把没有来源和实践的二手模型当作核心资产。
- 不用 AI 补造经历、客户、数据或结果。
