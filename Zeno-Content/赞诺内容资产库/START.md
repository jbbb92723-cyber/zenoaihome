# START｜今日入口

## 先问五个问题

1. 这份资料属于谁的经验？
2. 它服务哪个角色？
3. 这个角色正在完成什么目标？
4. 它解决什么真实问题，需要什么技能？
5. 它应沉淀为事实证据、案例、观点、方法、工具还是产品？

完整的外层分工见 [`资产库业务地图.md`](资产库业务地图.md)。如果资料已经明确是文稿、选题、案例或课程稿，再进入 dbskill 内容工程；不要把所有资料直接塞进内容结构化系统。

## 当前优先级

1. 补充可脱敏的真实案例和结果证据。
2. 把赞诺的 OPC 实践组织成角色知识体系。
3. 把知识变成可执行的清单、SOP、工具和服务。
4. 让星火者成员产生行动、复盘、案例和协作记录。
5. 将经验证据回流网站，建立可核验的信任。

## 最短工作闭环

```text
选一个角色
→ 定一个 30～90 天结果
→ 收一个真实问题
→ 做一个最小实践
→ 留下证据和资产
→ 再交给内容结构化系统加工
→ 发布 / 服务 / 星火者试用
→ 回填反馈与复盘
```

## 不做

- 不为了整理而整理。
- 不建新的平行知识库。
- 不把没有来源和实践的二手模型当作核心资产。
- 不用 AI 补造经历、客户、数据或结果。
