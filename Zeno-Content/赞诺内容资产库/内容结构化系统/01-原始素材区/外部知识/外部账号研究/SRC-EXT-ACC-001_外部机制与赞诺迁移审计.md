## 真正值得吸收的四个底层机制

### 1. 从输入导向转为生产导向

不是问「这条内容放哪」，而是问「它帮助哪个角色完成什么结果」。这与赞诺现有内容结构化系统兼容，但还需要把角色、结果和证据写进每轮实践。

### 2. 从课程顺序转为问题顺序

先遇到真实问题，再逆推技能与知识。对 OPC 而言，这能减少「学完再开始」；对星火者而言，读书会应服务成员当周的问题，而不是追求资料数量。

### 3. 按知识用途选择资产形态

事实进入可检索来源，程序进入清单和 SOP，概念进入定义、机制与边界。不是所有内容都要变成长文章，也不是所有收藏都值得进入主库。

### 4. 输出不是终点，使用结果才是

外部内容多停在输出和生产力。赞诺要继续追踪：谁使用、是否解决问题、产生什么结果、哪里失效、能否再次复用。这一步决定它是内容，还是经营资产。

## 不直接吸收的部分

- 「有了体系，做什么都会成功」属于过度承诺，不进入赞诺口径。
- 高度压缩的二手模型没有原始理论来源时，只能作启发。
- 页面 AI 章节摘要和 Whisper 机器稿都不是平台官方字幕。
- 账号互动数据只能说明公开互动，不能证明方法有效、受众付费或可复制。
- 角色体系不能替代市场选择、客户访谈、交付能力和真实结果。

## 已经形成的赞诺升级

```text
外部：角色 → 目标 → 问题 → 技能 → 知识

赞诺：角色 → 阶段目标 → 真实问题 → 判断与技能 → 知识
     → 实践动作 → 结果证据 → 可复用资产 → 产品或服务
     → 市场反馈 → 社群验证 → 复盘升级
```
