# 2026-08-13 外部逐字稿与角色经营体系升级

## 目标

从西西的思维笔记 13 条公开视频中提取可追溯逐字稿，识别可迁移机制，并在不冒充原创、不伪造验证结果的前提下，升级赞诺自己的角色知识体系。

## 原始资料处理

- 采集并校验 13 条公开作品的真实原声音轨。
- 确认页面没有可用官方字幕，采用本地 `whisper.cpp` 转写。
- 4 条核心视频使用 `small` 模型，完成关键术语语义校订。
- 其余 9 条使用 `base` 模型，保留机器原始转写状态。
- 每篇稿件写明来源、作品 ID、模型、校订状态和非官方字幕声明。
- MP3、Cookie、浏览器数据和临时媒体 URL 均未进入仓库。

## 方法论升级

外部内容提供的起点是：

```text
角色 → 目标 → 问题 → 技能 → 知识
```

赞诺结合 OPC、传统行业经验资产化、内容系统、网站和星火者，升级为：

```text
角色 → 阶段目标 → 真实问题 → 判断与技能 → 知识
→ 实践动作 → 结果证据 → 可复用资产 → 产品或服务
→ 市场反馈 → 社群验证 → 复盘升级
```

## 证据纪律

- 外部观点保持「外部启发」，不直接改名为赞诺原创。
- 赞诺现有但缺少原始记录的判断标记为「赞诺亲历」或「待验证」。
- 无来源的具体数字、虚构人物案例和机器转写错字不得作为有效证据。
- 方法状态要通过真实行动、用户使用、案例和反例升级，不能因文档完整而升级。
