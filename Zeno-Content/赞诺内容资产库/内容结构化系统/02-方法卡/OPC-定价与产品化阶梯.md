# OPC-定价与产品化阶梯

## 一句话定义
从卖时间（L1）到卖产品（L5）的五层定价升级路径——让你脱离"卖更多时间"的线性陷阱，一步步把收入天花板打开。

## 底层机制
```
卖时间(L1) → 卖项目(L2) → 卖月费(L3) → 卖效果(L4) → 卖产品(L5)
  服务打包      持续化        价值分成      可复制
```

每一层升级的核心不是"涨价"，而是改变你和客户之间的交易结构。

## 关键模型

### 五层定价层级

| 层级 | 收费方式 | 月收入天花板 | 例 |
|------|----------|-------------|-----|
| **L1：卖时间** | 按时/按天收费 | ≈时薪×160h | ¥200/h × 160h = ¥32,000 |
| **L2：卖项目** | 按项目固定价 | L1的1.5-2倍 | ¥15,000/品牌方案 |
| **L3：卖月费** | 按月订阅/长期合同 | L2的1.5-3倍 | ¥4,000/月内容运营 |
| **L4：卖效果** | 按客户获得的价值分成 | L3的2-5倍 | 增量收入的10-30% |
| **L5：卖产品** | 数字产品、课程、SaaS | 理论上无上限 | 课程¥199/份、工具¥99/月 |

### 产品化阶梯

```
       ┌─────────────────────────────┐
       │  L5 产品化：数字产品/SaaS    │  ← "我睡觉时也在赚钱"
       │  例：课程¥199/份、工具¥99/月  │
       ├─────────────────────────────┤
       │  L4 效果定价：按价值分成     │  ← "我帮你多赚100万，我分20万"
       ├─────────────────────────────┤
       │  L3 订阅化：月费/年费        │  ← "每个客户每月固定给我钱"
       ├─────────────────────────────┤
       │  L2 项目化：固定项目价        │  ← "一个项目多少钱，和时间脱钩"
       ├─────────────────────────────┤
       │  L1 时薪制：按时间收费        │  ← 收入=时间×时薪，天花板最明显
       └─────────────────────────────┘
```

### 升级路径与关键动作

| 升级 | 核心转变 | 关键动作 |
|------|----------|----------|
| **L1→L2** 卖时间→卖项目 | 把服务打包成有明确交付物的"产品" | 写"服务产品说明书"：包含什么、不包含什么、多长时间、多少钱 |
| **L2→L3** 卖项目→卖月费 | 找出服务中客户需要持续做的部分 | 问老客户："做完这个项目后，有什么需要持续帮忙的？" |
| **L3→L4** 卖月费→卖效果 | 服务能直接量化客户的价值增长 | 结构：基础费（覆盖成本）+ 效果分成（利润来源）；需要双方对"效果"定义一致 |
| **L4→L5** 卖效果→卖产品 | 把服务中积累的"方法"提取为可复制产品 | 产品化不是"不服务了"，而是"可复制部分变产品，不可替代部分保留为高价值服务" |

### 避坑

| 坑 | 表现 | 正解 |
|----|------|------|
| **全员L1陷阱** | 永远停在卖时间，因为"按小时收费最安全" | 安全=天花板最低 |
| **跨级跳跃** | 从L1直接跳L5，"我想做个课程" | 没有足够案例和口碑支撑课程可信度 |
| **定价过低** | 不敢涨价 | 涨价20%最多流失10%价格敏感客户，收入增长=1.2×0.9=1.08=增长8%。涨价几乎总是划算的 |

## 核心金句
- "安全=天花板最低。按小时收费最安全，也最赚不到钱。"
- "涨价20%，最多流失10%的价格敏感型客户，收入反而增长8%。涨价几乎总是划算的。"
- "产品化不是'不服务了'，而是把服务中可复制的部分变成产品，不可替代的部分保留为高价值服务。"

## Zeno迁移

### 对星火者
- 星火者入群时标注自己的定价层级（L1-L5），社群内按层级分组做"升级互助"
- 每季度做一次"涨价复盘"：谁涨了、涨了多少、丢了几个客户、实际收入变化如何——用真实数据打消恐惧
- L4→L5的案例最为稀缺，重点挖掘社群内已跑通产品化的成员，做深度案例分享

### 对OPC陪跑
- 陪跑核心KPI之一：帮助学员在3-6个月内完成一次层级跃迁（至少L1→L2）
- "服务产品说明书"是陪跑中最该逼学员写的一份文档——写出来，定价才从"感觉"变成"产品"
- 当学员说"我想做个课程"，先检查：你有多少个付费案例？你有多少口碑？——没积累的产品化=没灵魂的模板

### 对网站内容
- 制作"定价层级诊断器"：回答3个问题，系统告诉你现在在第几层、下一步该做什么
- 五篇文章分别详解L1-L5，每篇配真实案例+收入变化数据
- 免费资源："服务产品说明书模板"作为钩子产品，吸引邮箱订阅
- SEO关键词：自由职业者定价策略、一人公司产品化、OPC收入升级、按价值定价
