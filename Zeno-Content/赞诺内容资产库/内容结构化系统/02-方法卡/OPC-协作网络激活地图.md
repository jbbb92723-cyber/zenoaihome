# OPC-协作网络激活地图

## 一句话定义
从"一个人单干"进化为"有一个网络在背后支撑的超级个体"——用网络健康度自测+能力网络图+3月激活计划，系统化建设你的OPC协作生态。

## 底层机制
```
网络健康度自测 → 能力-关系网络图绘制 → 信任度评级 → 3个月激活（盘点→互荐→协作） → 标准化协作备忘录
```

一个人能走的路是有尽头的。你的网络不是名片夹，是战斗力——关键看你有多少个绿色节点（信任度≥★★★，合作过）。

## 关键模型

### 网络健康度自测

| # | 问题 | 是 | 否 |
|---|------|----|----|
| 1 | 能否在24小时内找到一个人帮你完成你不擅长的专业任务（设计/开发/翻译/法务）？ | | |
| 2 | 过去3个月内，你向其他人介绍过客户/机会？ | | |
| 3 | 过去3个月内，有人向你介绍过客户/机会？ | | |
| 4 | 你有一个"协作备忘录"模板，可和新协作者在10分钟内达成合作共识？ | | |
| 5 | 你参加过同一个线下/线上社区活动至少3次以上？ | | |

> 得分：每个"是"1分。≥4分=🟢网络健康，2-3分=🟡有基础但不够系统，≤1分=🔴信息孤岛

### 能力-关系网络图

```
        ┌─── 设计师A（合作过）────┐
        │   擅长：品牌VI、包装     │
        │   信任度：★★★☆         │
        │   分账：项目制，你留25%   │
        │                         │
 你 ───┼─── 开发者B（互介客户）──┼─── 客户X（你的客户）
 核心   │   擅长：小程序、网站     │     │
 能力   │   信任度：★★★★         │     │
 品牌   │   分账：按工时           │     │
 策略   │                         │     │
        ├─── 文案C（新认识的）────┤     │
        │   擅长：小红书、公众号   │     │
        │   信任度：★★☆          │     │
        │   分账：待定             │     │
        │                         │     │
        └─── 法务D（按需服务商）───┘
            擅长：合同审查、商标
            信任度：★★★
            分账：¥500/小时
```

> 网络评估：绿色节点（信任度≥★★★，合作过）≥3个→具备基础战斗力；<3个→优先升级2-3个黄色节点为绿色

### 3个月网络激活计划

| 月份 | 主题 | 任务 | 目标 |
|------|------|------|------|
| **第1月** | 盘点与连接 | 列出所有同行业/相邻行业的自由职业者/OPC；给5个最有协作潜力的人发消息："最近在做什么？有没有我能帮忙的？" | 不要一上来就谈合作，先建立"这个人靠谱"的认知 |
| **第2月** | 互荐测试 | 给你的2-3个客户推荐网络中其他OPC（当客户需要你不提供的服务时）；请网络成员在遇到不接的项目时推荐你 | 至少完成一次成功的互相推荐 |
| **第3月** | 小项目协作 | 找最信任的2个人，接一个需要三方协作的小项目；使用标准化协作备忘录 | 完成一次顺畅的三方协作，建立Trust Level 3 |

### 协作备忘录模板（10分钟版本）

```
项目：【项目名称】
金额：¥【总金额】
时间：【开始日期】→【截止日期】
分工：
- 【你的名字】：负责【具体交付物】，分成【%】
- 【协作者B】：负责【具体交付物】，分成【%】
约定：
- 修改上限：每模块免费改【2】次
- 付款节奏：客户付到我的对公账户后【3日】内转给协作者
- 保护期：项目结束后【6个月】内不绕过对方接触此客户
- 补位：如一方无法交付，提前【5天】通知，补位方多分【5%】
确认：【签名/微信确认】
```

### 避坑

| 坑 | 表现 | 正解 |
|----|------|------|
| **交浅言深** | 第一次聊就谈"我们一起做个大项目" | 先从小事开始 |
| **只有索取没有给予** | 只在需要帮忙时才出现 | 平时多介绍机会、多帮小忙 |
| **不约定就合作** | 觉得"大家都是朋友，不用搞那么正式" | 80%的协作纠纷都源于此 |

## Zeno迁移

### 对星火者
- 星火者社群本身就是OPC协作网络的实践场——每个成员入群时填写"能力标签+可协作方向"
- 社群内建立"互荐机制"：每月一次"客户需求交换"，把自己的客户需求中自己不做但别人能做的部分分享出来
- 协作备忘录模板作为星火者标准工具，所有协作项目必须使用，降低信任摩擦
- "3月网络激活计划"做成社群集体行动：第1月互相认识，第2月互相推荐，第3月合作小项目

### 对OPC陪跑
- 当学员进入复利期（框架1诊断≥13分），陪跑重点从"个人效率"转向"网络建设"
- 逼学员画出自己的能力-关系网络图——大部分人画完才发现自己的网络远比自己以为的薄弱
- "协作备忘录模板"在陪跑中强制执行——每次协作必须填写，养成"先约定后合作"的习惯

### 对网站内容
- 制作"网络健康度自测"交互工具，5题后自动判断：健康/需改进/信息孤岛
- "协作备忘录模板"作为免费下载资源，吸引邮箱订阅
- 能力网络图文章：教OPC如何画出自己的协作网络图，配真实案例（匿名化处理）
- SEO关键词：OPC协作网络、自由职业者互荐、一人公司外包协作、超级个体网络
