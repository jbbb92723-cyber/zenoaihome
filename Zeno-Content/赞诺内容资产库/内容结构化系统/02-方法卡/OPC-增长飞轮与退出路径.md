# OPC-增长飞轮与退出路径

## 一句话定义
OPC不是终点，是一段旅程——用增长阶段定位+飞轮模型驱动持续增长，再选择属于你的四种退出路径之一：无限游戏、品牌化、产品化退出、合并上岸。

## 底层机制
```
增长阶段诊断（生存/稳定/复利） → 飞轮启动（有效时薪>¥150） → 五大齿轮联动（提效→提价→增收→学习→品牌） → 选择退出路径（无限游戏/品牌化/产品化/合并）
```

OPC最大的陷阱不是"做不起来"，而是"做起来了但不知道为什么"。飞轮让你知道每个月在进步还是退步，退出路径让你知道最终要驶向哪里。

## 关键模型

### 增长阶段自测

| 指标 | 🌱 生存期 | 🌿 稳定期 | 🌳 复利期 |
|------|-----------|-----------|-----------|
| 月收入 | ¥3,000-10,000 | ¥10,000-30,000 | ¥30,000+ |
| 利润率 | 不稳定 | 60-80% | 70-90% |
| 客单价 | ¥500-3,000 | ¥3,000-15,000 | ¥15,000-50,000+ |
| 产品化收入占比 | 0% | <20% | >30% |
| 客户来源 | 主动找（100%） | 部分被动（20-50%） | 大量被动（>50%） |
| 协作者网络 | 0人 | 1-3人 | 5人+ |
| 有效时薪 | ¥50-100 | ¥150-300 | ¥500+ |

### OPC增长飞轮

```
        ┌────────────────────────────────────┐
        │                                    │
        ▼                                    │
 ① 提升单人产出 ──→ ② 提价/产品化 ──→ ③ 收入增长
 （AI+外包+工具）   （框架4）          （利润增加）
        │                                    │
        │                                    │
        └──── ⑤ 品牌资产增长 ←──── ④ 留出学习时间
             （口碑+内容+案例）    （框架3的深度工作）
```

> **飞轮启动条件**：有效时薪 > ¥150（≈月收入¥24,000+）。在此之前，优先任务是冲到启动线。
>
> **每月自检**：我的有效时薪比上个月涨了吗？如果没有，飞轮卡在哪里？

### 四种退出路径

| 退出路径 | 做什么 | 适合谁 | 信号 |
|----------|--------|--------|------|
| **1. 无限游戏** | 持续做OPC，享受利润和自由，做到退休 | 享受独处、对规模无欲望的人 | 每年收入稳定增长5-10%，生活满意度高 |
| **2. 品牌化** | 把"你这个人"变成一个品牌/IP | 有独特思想、善于表达的人 | 客户为"你"而来，不是为服务类型而来 |
| **3. 产品化退出** | 生意变成数字产品公司，不再依赖你的时间 | 有一定技术能力或强IP的人 | 产品化收入超过服务收入的50% |
| **4. 合并上岸** | 与互补的OPC合并，变成合伙制公司 | 找到了极强默契的协作伙伴 | 两人的协作收入持续超过各自独立收入 |

### OPC财务健康速检

| 指标 | 健康线 | 警戒线 |
|------|--------|--------|
| 月度固定支出 | 占月收入<50% | >70%=危险 |
| 紧急储备金 | ≥6个月固定支出 | <3个月=立即存钱 |
| 客户回款周期 | <30天 | >60天=现金流危险 |
| 单一客户收入占比 | <30% | >50%=脆弱 |
| 产品化收入占比（被动收入） | >20%（成熟期目标） | 0%且两年以上=天花板锁死 |

> **OPC财务第一原则**：你的固定支出越低，你的议价能力越强。因为你可以对不好的客户说"不"。

### 退出路径选择的三个禁忌

| 禁忌 | 正解 |
|------|------|
| 不要因为"做大了"就默认走公司化路径 | OPC的优势在于轻和小。不要把"收入增长"等同于"需要招人" |
| 不要过早追求被动收入 | 产品化（路径3）前需积累至少2-3年服务经验和案例。没积累的产品化=没灵魂的模板 |
| 不要在孤独中做退出决策 | 退出路径需要外部视角。找协作者网络、导师、用户聊，不要一个人闷头想 |
