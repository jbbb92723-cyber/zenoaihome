# OPC-技能市场匹配画布

## 一句话定义
用"擅长度×付费意愿×AI抵抗度"三维公式找到你的甜蜜点，避免把兴趣当生意、把夕阳技能当方向。

## 底层机制
```
列出所有技能 → 三维评分（擅长/付费意愿/AI抵抗度） → 甜蜜点公式筛选 → 四区域矩阵定位 → 针对性行动方案
```

你不是没有选择，你是没有把选择摆到桌面上一个一个看过。

## 关键模型

### 甜蜜点公式

> **擅长度 ≥ 3 且 付费意愿 ≥ 3 且 AI抵抗度 ≥ 3**

对每个技能按以下标准评分（1-5分）：

| 维度 | 1分 | 2分 | 3分 | 4分 | 5分 |
|------|-----|-----|-----|-----|-----|
| 你有多擅长？ | 入门级 | 能独立完成 | 比大多数同行好 | 行业前20% | 顶尖 |
| 市场愿付多少钱？ | 几乎不付费 | 低客单价<¥1,000 | 中等¥1,000-10,000 | 高¥10,000-50,000 | 很高¥50,000+ |
| AI能替代多少？ | AI完全替代 | AI替代70%+ | AI替代50% | AI辅助但人不可缺 | AI几乎无法替代 |

### 四区域矩阵

| | 低付费意愿（1-2分） | 高付费意愿（3-5分） |
|---|---|---|
| **高擅长+高AI抵抗** | 🟡 爱好区：你很擅长但市场不认 | 🟢 **甜蜜点 ← 这就是你的OPC方向** |
| **低擅长或低AI抵抗** | 🔴 放弃区：不值得投入 | 🟠 成长区：有需求但需提升或被AI替代风险高 |

### 行动方案

| 你的状态 | 行动 |
|----------|------|
| 有技能在🟢甜蜜点 | 直接围绕它设计核心服务，进入框架3 |
| 都在🟡爱好区 | 做市场调研：换行业/客户群/包装方式，能不能提升付费意愿？ |
| 都在🟠成长区 | 选一个投入产出比最高的，给它3个月集中提升 |
| 都在🔴放弃区 | 诚实面对：现有技能可能不适合做OPC，需要学新技能 |

### 避坑：最常见的三个错误

| 错误 | 正解 |
|------|------|
| 把"兴趣"当"甜蜜点" | 你喜欢的不等于市场愿意付钱 |
| 选了AI正在快速替代的方向 | 纯翻译、基础平面设计、简单数据录入——选AI抵抗度高的 |
| 技能太泛："我很擅长沟通" | 这不叫技能。具体到"我能帮B2B SaaS公司写出转化率3%+的英文官网文案" |

## 核心金句
- "把兴趣当甜蜜点——你喜欢的不等于市场愿意付钱的。"
- "'我擅长沟通'不叫技能。具体到'我能帮B2B SaaS公司写出转化率3%+的英文官网文案'才叫技能。"
- "技能太泛等于没有技能——市场不为人付费，市场为解决具体问题的能力付费。"

- 星火者线下活动做"技能匹配工作坊"：每人带5-10个技能列表，小组互相帮忙打分并填入四区域矩阵

### 对OPC陪跑
- 陪跑初期核心交付：帮学员完成一次完整的技能-市场匹配画布，这是后续所有框架的前提

- 尤其警惕学员把"曾经做过的工作"当成"擅长且值得卖的技能"，需要外部视角校准
