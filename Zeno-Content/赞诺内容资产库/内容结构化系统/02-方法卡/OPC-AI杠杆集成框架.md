# OPC-AI杠杆集成框架

## 一句话定义
用"诊断→决策矩阵→四周计划"三步法，把AI系统化嵌入全部业务环节——不是偶尔用一下，而是让AI成为你的产能杠杆。

## 底层机制
```
业务全流程扫描 → AI集成度打分 → 决策矩阵（频次×判断力） → 优先级排序 → 四周深度集成计划
```

"AI负责广度，你负责深度"——不是所有环节都该深度AI化。高频低判断=全自动，高频高判断=AI辅助+人决策，低频=不值得花时间搭AI流程。

## 关键模型

### AI集成成熟度自测

对每个业务环节评估AI集成度（1-5分，1=完全人工，5=AI全自动）：

| 业务环节 | AI集成度（1-5） | 你现在怎么做的 | AI可以帮什么 |
|----------|:--:|---------------|-------------|
| 市场研究 | | | 分析趋势、整理竞品、提炼客户反馈 |
| 内容创作 | | | 初稿、改写、翻译、多版本测试 |
| 客户沟通 | | | 邮件草稿、提案摘要、常见问题自动回复 |
| 核心交付 | | | 辅助分析、生成草稿、质量检查 |
| 项目管理 | | | 安排日程、提醒节点、标准化检查 |
| 财务行政 | | | 发票整理、费用分类、税务计算辅助 |
| 学习提升 | | | 文章总结、新工具评估、知识库管理 |

> 平均分 ___/5：≥4分=AI原生OPC，2-3分=需全面诊断，≤1分=正在被AI时代的OPC甩开

### AI集成决策矩阵

| | 高频次（每周多次） | 低频次（每月几次） |
|---|---|---|
| **高判断**（需要你的专业经验） | 🟡 AI辅助：AI出草稿，你决策 | 🟢 自己上：不值得花时间搭AI流程 |
| **低判断**（规则明确） | 🟢 全自动：AI直接完成，你抽查 | 🟡 AI+抽查：AI做，你检查一次 |

### 四周AI深度集成计划

| 周 | 主题 | 任务 | 产出 |
|----|------|------|------|
| **第1周** | 诊断周 | 列出每周重复3次以上的所有任务；对每个任务打分AI可替代程度（1-5）；选出得分最高的3个任务优先AI化 | 3个优先AI化任务清单 |
| **第2周** | Prompt周 | 为选出的3个任务编写固定Prompt；每个Prompt达到"换一个输入变量就能直接用"的标准；测试3-5次，每次改进Prompt | 3个可复用的固定Prompt |
| **第3周** | 工作流周 | 把3个任务串联：上一个AI输出→下一个AI输入；触发整个工作流只需一个动作（如"收到客户需求邮件"）；工具：飞书多维表格+AI / Notion AI / n8n / Make | 1条端到端AI工作流 |
| **第4周** | 评估周 | 测算AI化前后的时间对比；把省下的时间投入深度工作（框架3）或学习（下一轮AI化）；确定下一轮AI化的3个任务 | 效率对比报告+下轮目标 |

### 避坑

| 坑 | 表现 | 正解 |
|----|------|------|
| **AI万能主义** | 以为AI什么都能做→什么都让AI做→质量全面下降→放弃AI | "AI负责广度，你负责深度" |
| **完美Prompt陷阱** | 花3小时打磨一个"完美"Prompt→只用了一次→下次换场景又要重新打磨 | Prompt是迭代出来的，不是设计出来的 |
| **忽视AI成本** | 每月AI工具订阅从¥200膨胀到¥2,000+ | 每季度审查：哪些工具过去30天用了10次以上？取消其余的 |

## 核心金句
- "AI负责广度，你负责深度。"
- "Prompt是迭代出来的，不是设计出来的。"
- "每季度审查一次AI工具订阅——过去30天用了不到10次的，取消。"
