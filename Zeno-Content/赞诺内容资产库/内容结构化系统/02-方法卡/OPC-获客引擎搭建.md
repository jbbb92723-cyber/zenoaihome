# OPC-获客引擎搭建

## 一句话定义
用"播种→钩子→核心服务"三层漏斗，把获客从碰运气变成可预期、可复制的系统。

## 底层机制
```
获客健康度自测 → 三层漏斗搭建（播种→钩子→核心服务） → 90天执行计划 → 避开五大无效努力
```

获客不是找客户，是让客户找到你。三层漏斗的本质：免费内容让人知道你→低价体验让人试你→高价服务让人信你付你。

## 关键模型

### 获客健康度自测

| 指标 | 🔴 危险 | 🟡 一般 | 🟢 健康 |
|------|---------|---------|---------|
| 客户集中度 | 一个客户占>50%收入 | 最大客户占30-50% | 最大客户占<30% |
| 获客渠道数量 | 只有一个渠道 | 2个渠道 | 3个以上独立渠道 |
| 老客户复购/转介绍率 | <20% | 20-50% | >50% |
| 被动获客占比 | 0%（全靠主动找） | <30% | >30%客户主动找上门 |
| 客户获取成本 | 不知道 | 知道但很高 | 知道且可控 |

### 获客三层漏斗

```
第一层：播种（免费内容，广撒网——让陌生人知道你存在）
 ├── 社交媒体内容（公众号/小红书/知乎/推特）
 ├── 社区分享（线上线下的免费分享）
 ├── 帮助他人（在群里认真回答专业问题）
 └── SEO/作品集（让谷歌和百度收录你的案例）
      ↓ 转化率约 1-5%

第二层：钩子（低价体验，筛选意向客户——让感兴趣的人低成本试你）
 ├── 轻咨询/诊断（¥99-299/30-60分钟）
 ├── 行业报告/白皮书（¥49-199，展示专业深度）
 ├── 迷你版服务（正价20-30%，降低决策门槛）
 └── 公开工作坊（¥199-499/人，一对多）
      ↓ 转化率约 20-40%

第三层：核心服务（高价服务，你的利润来源——让信任你的人付高价）
 ├── 项目制服务
 ├── 月费/订阅制服务
 ├── 效果分成制服务
 └── 高端咨询服务
```

### 90天获客引擎搭建计划

| 周 | 任务 | 产出 |
|----|------|------|
| 第1-2周 | 确定内容主题（你专业领域中客户最常问的10个问题） | 10个内容标题+提纲 |
| 第3-6周 | 每周发布2-3篇干货内容在1-2个平台上 | 8-12篇内容上线 |
| 第7-8周 | 设计1-2个钩子产品并上线 | 轻咨询页面上线 |
| 第9-10周 | 每天在2-3个相关社区/群回答专业问题 | 建立"这个人是专家"的认知 |
| 第11-12周 | 分析数据——哪个内容带来最多咨询？哪个钩子转化最高？ | 确定最高ROI渠道，加倍投入 |
| 第13周 | 启动老客户转介绍计划（每个满意客户请推荐1个朋友） | 转介绍流程上线 |

### 五大无效努力

| 无效努力 | 为什么无效 | 换成什么 |
|----------|-----------|----------|
| 所有平台都发一遍 | 精力分散，哪个都做不好 | 选1-2个平台深耕 |
| 发"我多厉害"的内容 | 没人关心你多厉害 | 发"你能学到什么"的内容 |
| 买广告/买流量 | OPC利润率支撑不了付费获客 | 用内容做免费获客 |
| 只发不互动 | 内容没人看因为没有社交分发 | 花50%时间评论和回复 |
| 参加所有社交活动 | 广撒网效率极低 | 参加垂直行业活动，去同一个活动3次以上 |

## 核心金句
- "获客不是找客户，是让客户找到你。"
- "没人关心你多厉害——发'你能学到什么'的内容。"
- "花50%时间评论和回复——内容没人看，是因为没有社交分发。"
