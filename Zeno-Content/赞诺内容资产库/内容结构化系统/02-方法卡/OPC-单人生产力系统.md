# OPC-单人生产力系统

## 一句话定义
OPC的"生产资产"就是你自己——管理好注意力、创造力、体力三个账户，让一个人稳定产出团队级的成果。

## 底层机制
```
三账户模型（注意力/创造力/体力） → 存量保护 → 消耗识别 → 危险信号预警 → 每周模板固化 → 避开生产力陷阱
```

"秒回客户消息"消耗的是你的注意力账户，不是生产力。真正的生产力来自你在深度工作时间里创造的不可替代价值。

## 关键模型

### 生产力健康度自测

| # | 问题 | 是 | 否 |
|---|------|----|----|
| 1 | 你每天有至少3小时不受打扰的深度工作时间？ | | |
| 2 | 你每周至少有一天完全不看工作消息？ | | |
| 3 | 你过去一个月没有因为"太忙"而错过截止日期？ | | |
| 4 | 你的工作流中有至少3个环节被AI或自动化工具替代？ | | |
| 5 | 你知道你上一个月的有效时薪是多少？ | | |

> 得分：每个"是"1分。≥4分=🟢健康，2-3分=🟡需调整，≤1分=🔴严重问题

### 三账户模型

| 账户 | 存什么 | 耗什么 | 最低维护标准 | 危险信号 |
|------|--------|--------|-------------|----------|
| **注意力账户** | 深度睡眠、冥想、中断保护 | 多任务切换、通知、社交媒体 | 每天≥3h深度工作 | 一天结束时想不起做了什么重要的事 |
| **创造力账户** | 跨界阅读、独处、新体验 | 重复性工作、信息过载 | 每周≥5h"无目的输入" | 产出质量在下降但不知道为什么 |
| **体力账户** | 睡眠、饮食、运动 | 熬夜、久坐、咖啡因依赖 | 每天≥7h睡眠，每周≥2次运动 | 下午三点必须靠咖啡撑过去 |

### 每周模板

| 日期 | 时段 | 内容 |
|------|------|------|
| **周一：规划日** | 上午（深度3h） | 本周最重要的1个交付物 |
| | 下午（浅层2h） | 回邮件、开发票、更新社交媒体 |
| **周二-周四：执行日** | 上午（深度3-4h） | 核心交付工作 |
| | 下午（浅层2h） | 客户沟通、外包协调、学习 |
| | 晚间（可选1h） | 记录当天收获和待改进点 |
| **周五：连接日** | 上午（深度2h） | 完成本周收尾 |
| | 下午（连接3h） | 社区活动、见人、客户回访 |
| **周六：自由日** | 全天 | 完全不工作，或只做"热爱但不赚钱"的事 |
| **周日：准备日** | 晚上30分钟 | 规划下周的TOP3任务 |

### 避坑

| 坑 | 表现 | 正解 |
|----|------|------|
| 把"响应速度快"当生产力 | 秒回客户消息 | 消耗的是注意力账户，不是生产力 |
| 工具太多 | 每加一个新工具，切换成本就多一层 | 工具精简到≤10个 |
| 周末补进度 | 周末补的不是进度 | 是下周的精力亏损 |

## 核心金句
- "OPC的'生产资产'就是你自己。管理自己就是管理三个账户：注意力、创造力、体力。"
- "秒回客户消息消耗的是你的注意力账户，不是生产力。"
- "周末补的不是进度，是下周的精力亏损。"
