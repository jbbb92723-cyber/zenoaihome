# 提示词与 Agent 工具层

> 这里保存执行工具、提示词和 Agent 协作资料。工具帮助完成动作，但不替代角色判断、原始证据或内容单元真源。

## 分层

- `提示词库-v2.md`：当前可调用的提示词入口，使用前核对适用范围。
- `Agent/`：当前 Agent 协作资料和规则。
- `归档/`：历史提示词和已停用方案，不作为当前默认规则。

## 使用边界

1. 先从 `资产库业务地图.md` 和对应真源确定角色、问题和证据。
2. 再选择提示词或 Agent 执行动作。
3. 工具输出必须回到原始来源、项目记录或内容结构化系统复核。
4. 提示词文件里出现的示例 ID、旧路径和旧口径不自动成为当前事实。
