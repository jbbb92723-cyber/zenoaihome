# Zeno OS

> 不是把知识收藏起来，而是把经验变成能力、行动和选择权。

## 总路径

```text
赞诺的 OPC 实践
  → 经验资产化
  → 角色知识体系
  → 内容、工具、服务与产品
  → 网站建立信任
  → 星火者验证行动与协作
  → 为传统行业实践者增加职业自主权
```

## 五个工作面

| 工作面 | 入口 | 产出 |
|---|---|---|
| 身份与定位 | `_品牌定位/` | 我是谁、为谁服务、凭什么值得信任 |
| 知识与经验 | `内容结构化系统/` | 角色、问题、技能、证据、方法和工具 |
| 发布与产品 | `_发布与产品/` | 视频、公众号、网站素材、产品表达 |
| OPC 专题 | `内容资产/OPC白皮书/` | 白皮书、实战框架、政策与研究原件 |
| 共同体实践 | `星火者/` | 成员角色地图、行动、复盘、项目和协作信用 |

## 角色知识体系的基本单位

```text
角色
→ 阶段目标
→ 真实问题
→ 判断与技能
→ 事实性 / 程序性 / 概念性知识
→ 实践动作与结果证据
→ 可复用资产
→ 产品或服务
→ 市场反馈与复盘升级
```
