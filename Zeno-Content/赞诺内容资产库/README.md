## 当前主线

```text
真实经验
→ 经验资产化
→ 角色知识体系
→ 网站 / 公众号 / 视频 / 工具 / 服务
→ 星火者真实行动与协作
→ 新的案例、方法和信任证据
```

这里有两条不同层级的逻辑：`内容结构化系统` 负责把素材加工成内容单元、主题地图和选题装配；资产库外层的角色经营逻辑负责决定服务谁、验证什么、留下什么证据，以及如何回到产品、发布和社群。不要把两者当成同一套目录规则。

## 工作原则

- 先查来源，再提炼。
- 原始资料与加工结果分开。
- 外部观点不直接冒充赞诺观点。
- 不按“装修 / AI / OPC”堆文章，优先按角色的目标、问题和技能组织。
- 内容最终要能支持理解、行动、信任或协作，否则不值得继续扩张。
