## 基本信息

| 项目 | 内容 |
|------|------|
| 时长 | 1天（8小时，含午休1.5h + 茶歇2次共30min），纯教学6h |
| 人数 | 3-10人小班 |
| 定价 | ¥1,999-2,999/人 |
| 地点 | 东盟谷 |
| 学员画像 | 传统行业老板/个体经营者，AI零基础或仅浅度使用 |
| 学员准备 | 手机+笔记本电脑（纯手机也可参与，电脑体验更好） |

## 课程目标

一天结束后，每个学员能带走三样东西：

1. **一件作品**：用AI完成一个自己业务的真实任务
2. **一套心法**：掌握"提示词四要素"，能独立写出可复用的提示词
3. **一个动作**：一个"小到不可能失败"的课后行动承诺

## 课程设计原则（721）

- **10%讲**：只讲Zeno的亲身判断，不讲通用理论
- **20%讨论**：小组互评、互相测试、经验分享
- **70%实操**：每个模块都有动手环节，模块五是全天核心

导师记录每个学员的行业，为下午实战做准备。

**环节2：我的AI故事 (15min)**

> 💡 这个环节不是在"讲课"，是在用Zeno的真实经历破除三个最大迷思。

**讲（10min）：**

"我先说说我自己。做了17年传统生意，半年前我跟你们一样——觉得AI是程序员的事，跟我没关系。"

**迷思一：❌ "AI很难用，我学不会"**

> 📍 Z-36：从工具收集癖到极简工具链
> 📍 坑①（Z-45）：追最强工具→忘了自己的需求

"我最开始也觉得难。下载了ChatGPT，要开梯子、要注册、全英文。后来发现小米手机里自带的'小爱同学'就能用AI，微信里搜'豆包'就能用。不是AI难，是我在追'最强工具'而不是'够用工具'。"

**迷思二：❌ "AI写的东西很假，用不了"**

> 📍 Z-05：不教一键AI低质内容
> 📍 Z-02：传统经验×AI是独特优势

"AI写得假，是因为你没教它说人话。你想让一个不认识你的人帮你写一段介绍——它能不假吗？但如果你告诉它'我是做XX的，我的客户是XX，用口语写'，出来东西就完全不同。今天你就能亲眼看到这个变化。"

**迷思三：❌ "AI会替代我"**

> 📍 Z-01：落地比概念值钱一百倍

"AI替代的是不用AI的人，不是用AI的人。做了17年生意，我学会一件事：落地比概念值钱一百倍。AI落地到你的生意里，它就是你的工具；你不落地，它就是你焦虑的来源。今天一天，我们只做一件事——让AI在你的生意里落地。"

### 模块二：动手第一课 (9:30-10:30, 60min)
**比例：讲10% + 练70% + 评20%**

**调用的知识点：Z-07, Z-10, Z-27**

---

**环节1：选工具+注册 (5min)**

> 📍 Z-27：AI工具选型对比

推荐：Kimi / 豆包 / 通义千问（免费、中文好、不需梯子）

导师说："这三个我都用过。今天不教每个怎么用，你选一个最顺手的，我们只做一件事——让它帮你说人话。"

（提前发注册指南到群里，现场只帮卡住的）

---

**环节2：三轮递进练习 (40min)**

> 📍 Z-10：反工具化学习——不学工具，学AI思维

| 轮次 | 提示词 | 目的 | 导师解说 |
|------|--------|------|----------|
| 第一轮 | "帮我写一段业务介绍" | 体验：AI不懂你的时候有多假 | "你看，这就是我半年前的水平——出来的东西像机器人写的对吧？" |
| 第二轮 | "我是做XX的，我的客户是XX，帮我写一段业务介绍" | 发现：多加一句信息，效果天差地别 | "只加了一句话——我是谁、我的客户是谁——你看变化多大。" |
| 第三轮 | "我是做XX的，客户是XX。用口语化方式写，不要广告腔，像朋友聊天一样。100字以内。" | 掌握：约束和风格决定输出质量 | "再加两个限制——风格、字数。现在这段话，像不像你平时跟客户聊天？" |

每轮写完后，让学员把结果发到群里，导师挑2-3个典型案例展示对比。

---

**环节3：互评讨论 (15min)**

> 📍 Z-07：信任崩塌的时代，瑕疵无价

两人一组，互相看三轮的变化。

导师引入一个关键判断：

"你们觉得第三轮出来的东西，能直接发吗？"

→ 大多数学员说"还差点意思"

"对。这就是我今天要教你们最重要的一件事——**AI做70分，你改到90分。不要追求AI输出100分——那是不可能的，而且越改越假。** 我的公众号文章从来不是AI直接发的，AI出初稿→我改语言→加入我的案例→发出。读者看到的不是'一篇AI范文'，是'一个真实的人在说话'。"

**环节1：讲——提示词四要素 (10min)**

> 📍 Z-15：提示词四要素

"这个框架不是我从书上看来的——是我用了几个月AI、写了上百条提示词之后自己总结的。"

（展示真实截图：Zeno最早写的提示词——只有一句话 "帮我写一段装修介绍" ——和现在写的提示词——结构完整的四要素）

```
┌─────────────────────────────────────┐
│           提示词四要素               │
│           Zeno踩了上百个坑总结的     │
├──────────┬──────────────────────────┤
│ 1. 角色   │ 你是谁、AI扮演谁         │
│ 2. 任务   │ 具体要做什么             │
│ 3. 约束   │ 不要什么、字数、风格     │
│ 4. 输出   │ 用什么格式呈现           │
└──────────┴──────────────────────────┘
```

"90%的人觉得AI不好用，是因为他们只给了'任务'。四要素齐全的提示词，效果好5倍——这是我实测的数据。"

**坑⑤（Z-49）：AI完美主义**

"但是注意——不要改太多轮。我最惨的一次，让AI改一段文案改了8轮，每轮只改进5%，花的时间够我自己重写三遍了。**AI迭代的收益递减拐点在第3-4轮，超过这个点，人工接手。**"

---

**环节2：练——每人写3个自己业务的提示词 (50min)**

| 序号 | 练习内容 | 四要素拆解 | 场景 |
|------|----------|-----------|------|
| 提示词1 | 让AI帮你回复一个难缠的客户 | 角色=客服专家，任务=回复客户，约束=不激化矛盾+口语化，输出=一段话 | 客服 |
| 提示词2 | 让AI帮你想3个本周发朋友圈的选题 | 角色=内容策划，任务=给选题，约束=跟XX行业相关+不油腻，输出=列表 | 营销 |
| 提示词3 | 让AI帮你整理一个产品的卖点清单 | 角色=产品经理，任务=提炼卖点，约束=客户视角+每点一句话，输出=表格 | 销售 |

每写一个就跑一遍，不满意就改提示词再跑。导师巡场指导。

**环节3：互评 (15min)**

## 下午场｜场景→实战→资产 (13:30-17:00)

### 模块四：AI + 你的生意 (13:30-14:15, 45min)
**比例：讨论50% + 引导演示50%**

**调用的知识点：Z-11, Z-16, Z-21, Z-26**

---

**环节1：小组讨论——找时间黑洞 (20min)**

> 📍 Z-11：从业务问题出发，不从工具功能出发
> 📍 Z-26：消解问题优先于回答问题

"很多人学AI的第一个问题是'AI能做什么'——这是错误的起点。正确的问题是'我生意里什么最费时间'。"

发"时间黑洞清单"，每人勾选：
- 回客户微信/消息
- 写文案/发朋友圈/做海报
- 做报价/合同/方案
- 整理资料/找旧文件
- 回答重复问题
- 做表格/算账
- 学新东西/看同行在做什么

每组选出TOP3时间黑洞，贴到白板上。

**导师引导语：** "看到了吗？你们不需要问'AI适不适合我的行业'——你在时间黑洞清单上勾出来的每一项，AI都能帮你。问题从'能不能'变成了'先做哪个'。"

---

**环节2：导师引导——AI切口判断法 (25min)**

> 📍 Z-16：AI切口判断法（四问）
> 📍 Z-21：从右到左倒推法

核心原则：

> 这个任务AI能做70分，就值得用AI。必须做到95分的，先别用AI。

给"AI切口四问"：

```
1. 这件事有套路吗？
   有 → AI能做。没有 → 别用AI。

2. 这件事需要我的独特判断吗？
   不需要 → AI能做。需要 → 你做判断，AI做辅助。

3. 这件事做错了代价大吗？
   不大 → 放手让AI做。大 → AI出初稿，你审。

4. AI做完我改一下能用吗？
   能 → 马上用。不能 → 换个任务。
```

现场演示2-3个学员的真实场景：
- 选一个学员的时间黑洞
- 现场用四问判断 → 写提示词 → 跑AI
- 对比"人工做"和"AI辅助做"的时间差

"看到了吗？从右边的问题（什么费时间）往左边推（AI怎么解决），而不是从左边（AI能做什么）往右边猜（能不能用在我生意里）。"

**比例：练90% + 导师1v1巡场10%**

**调用的知识点：Z-12, Z-17, Z-30, Z-31, Z-04, 坑⑤**

> 📍 Z-12：用真实项目驱动学习
> "不做练习题，做你真实需要的东西。你今天做的这个作品，离开教室就能用。"

每个学员独立完成一个真实任务。

**任务菜单（选一个）：**

| # | 任务 | 适合谁 | 导师可分享的Zeno故事 |
|---|------|--------|---------------------|
| ① | 写一篇本周发朋友圈/公众号的内容 | 内容获客 | Z-31：我的AI内容创作工作流 |
| ② | 整理一份客户常问问题 + AI回答模板 | 客服压力大 | Z-02：传统经验×AI = 专属客服 |
| ③ | 做一个产品的AI销售话术 | 做销售 | 我的第一个AI销售话术是怎么调出来的 |
| ④ | 用AI帮你分析一条竞品的内容 | 做市场 | Z-17：AI做分析的收益递减拐点 |
| ⑤ | 把你的经验整理成一份"新人培训清单" | 带团队 | Z-08：经验系统化 |
| ⑥ | 自定义：带一个你自己的真实任务 | 所有 | — |

**流程：**

1. 选任务 + 写提示词（5min）
2. AI出第一版（10min）
3. 自己改 + 让AI再改 → **循环3轮**（60min）
   - 📍 坑⑤：为什么是3轮？因为超过3轮收益递减——这是我的真实教训
4. 导师1v1巡场指导（全程）
   - 这时候导师展示Z-30：展示zenoaihome.com是怎么用AI搭出来的——"我也不会写代码，但AI帮我搭了一个完整的商业网站。你们今天做的这个任务，难度不会超过搭网站。"

5. 最后15min：每人展示最终作品（投影到大屏）

> 📍 Z-04：作品思维 > 流量思维
> 导师收尾："今天在场的每个人，都带走了一件作品。这件作品就是你最好的名片。下次有人问你'学AI有什么用'——把这件作品发给他看。"

"收藏夹是坟墓——存了不看、看了找不到、找到了不会用。资产库是武器库——分类+标签+场景→3秒找到→马上用。"

**演示（20min）：Zeno的AI资产库长什么样**

> 📍 Z-28：Obsidian知识库
> 📍 Z-38：方法卡沉淀系统

现场打开Zeno的真实AI资产库，演示三个动作：
1. 把今天写的最好的提示词存进去

3. 搜一下：想找一个"朋友圈"相关的提示词，3秒找到

"这就是我今天用的系统。每次用AI产出好东西→马上存→分类→标签。现在我有上百条提示词，每一条3秒找到。这个系统，你们今天就可以开始建。"

**给模板：极简"我的AI资产库"模板**

```
│   ├── 客户沟通类
│   ├── 内容创作类
│   ├── 销售辅助类
│   └── 整理分析类
├── 📸 好结果截图

```

工具选择：飞书文档 / 微信收藏夹 / 手机备忘录——哪个顺手用哪个。"不用学新工具，只用你已经会用的。"
