# AI小白实战营——一天让AI变成你的第一个员工

> 课程分层定位：小白课（本大纲）→ 进阶课 → 企业科普 → 企业应用 → 孵化IP

## 基本信息

| 项目 | 内容 |
|------|------|
| 时长 | 1天（8小时，含午休1.5h + 茶歇2次共30min），纯教学6h |
| 人数 | 3-10人小班 |
| 定价 | ¥1,999-2,999/人 |
| 地点 | 东盟谷 |
| 学员画像 | 传统行业老板/个体经营者，AI零基础或仅浅度使用 |
| 学员准备 | 手机+笔记本电脑（纯手机也可参与，电脑体验更好） |

## 课程目标

一天结束后，每个学员能带走三样东西：

1. **一件作品**：用AI完成一个自己业务的真实任务
2. **一套心法**：掌握"提示词四要素"，能独立写出可复用的提示词
3. **一个动作**：一个"小到不可能失败"的课后行动承诺

## 课程设计原则（721）

> 参考：[[SOL-20260709-003_学习金字塔与721培训设计法]]
> 被动学习留存率<30%，主动学习（讨论+实践+教授）留存率70%+

- **10%讲**：只讲核心概念，控制在每模块5-15分钟
- **20%讨论**：小组互评、互相测试、经验分享
- **70%实操**：每个模块都有动手环节，模块五是全天核心（90分钟纯实战）

## 上午场｜认知→动手→心法 (9:00-12:00)

### 模块一：认知破冰 (9:00-9:30, 30min)
**比例：讲30% + 讨论70%**

**环节1：自我介绍+破冰 (15min)**
- 每人1分钟："我是做什么的 + 为什么今天来"
- 导师记录每个学员的行业，为下午实战做准备

**环节2：认知重塑 (15min)**

讲（10min）：一个17年传统生意人的AI真实使用体验
- 我不用AI做什么：一键生成垃圾内容、替代我的判断、假装我很懂
- 我用AI做什么：整理经验、回答客户问题、写初稿、做思考膨胀

破除三个迷思：
1. ❌ "AI会替代我" → ✅ AI替代的是不用AI的人
2. ❌ "学AI要懂技术" → ✅ 会用微信就会用AI
3. ❌ "AI写的东西很假" → ✅ 是你没教它说人话

---

### 模块二：动手第一课 (9:30-10:30, 60min)
**比例：讲10% + 练70% + 评20%**

参考观点卡：[[不要学工具，要学AI思维]]

**环节1：选工具+注册 (5min)**
- 推荐：Kimi / 豆包 / 通义千问（免费、中文好、不需梯子）
- 提前发注册指南到群里，现场只帮卡住的

**环节2：三轮递进练习 (40min)**

| 轮次 | 提示词 | 目的 |
|------|--------|------|
| 第一轮 | "帮我写一段业务介绍" | 体验：AI不懂你的时候有多假 |
| 第二轮 | "我是做XX的，我的客户是XX，帮我写一段业务介绍" | 发现：多加一句信息，效果天差地别 |
| 第三轮 | "我是做XX的，客户是XX。用口语化方式写，不要广告腔，像朋友聊天一样。100字以内。" | 掌握：约束和风格决定输出质量 |

每轮写完后，让学员把结果发到群里，导师挑2-3个典型案例展示对比。

**环节3：互评讨论 (15min)**
- 两人一组，互相看三轮的变化
- 聊一个话题："哪一版最像你平时说话？为什么？"

### 模块三：提示词核心心法 (10:45-12:00, 75min)
**比例：讲15% + 练70% + 评15%**

**环节1：讲——提示词四要素 (10min)**

```
┌─────────────────────────────────────┐
│           提示词四要素               │
├──────────┬──────────────────────────┤
│ 1. 角色   │ 你是XXX领域的专家         │
│ 2. 任务   │ 帮我做XXX                 │
│ 3. 约束   │ 不要XXX，字数XXX，风格XXX  │
│ 4. 输出   │ 用表格/列表/段落呈现       │
└──────────┴──────────────────────────┘
```

**环节2：练——每人写3个自己业务的提示词 (50min)**

| 序号 | 练习内容 | 场景 |
|------|----------|------|
| 提示词1 | 让AI帮你回复一个难缠的客户 | 客服场景 |
| 提示词2 | 让AI帮你想3个本周发朋友圈的选题 | 营销场景 |
| 提示词3 | 让AI帮你整理一个产品的卖点清单 | 销售场景 |

每写一个就跑一遍，不满意就改提示词再跑。导师巡场指导。

**环节3：互评 (15min)**
- 两人一组，交换测试对方的提示词
- 选出"全班最佳提示词"，导师点评为什么好

## 下午场｜场景→实战→资产 (13:30-17:00)

### 模块四：AI + 你的生意 (13:30-14:15, 45min)
**比例：讨论50% + 引导演示50%**

**环节1：小组讨论——找时间黑洞 (20min)**

发"时间黑洞清单"，每人勾选：
- 回客户微信/消息
- 写文案/发朋友圈/做海报
- 做报价/合同/方案
- 整理资料/找旧文件
- 回答重复问题
- 做表格/算账
- 学新东西/看同行在做什么

每组选出TOP3时间黑洞，贴到白板上。

**环节2：导师引导——AI切口判断法 (25min)**

核心原则：
> 这个任务AI能做70分，就值得用AI。必须做到95分的，先别用AI。

现场演示2-3个学员的真实场景：
- 选一个学员的业务场景
- 现场写提示词、跑AI、迭代
- 对比"人工做"和"AI辅助做"的时间差

给"AI切口四问"：
1. 这件事有套路吗？（有→AI能做）
2. 这件事需要我的独特判断吗？（不需要→AI能做）
3. 这件事做错了代价大吗？（不大→AI能做）
4. AI做完我改一下能用吗？（能→马上用）

---

### 模块五：实战工作坊 (14:15-15:45, 90min) 🔥 全天核心
**比例：练90% + 导师1v1巡场10%**

每个学员独立完成一个真实任务。

**任务菜单（选一个）：**

| # | 任务 | 适合谁 |
|---|------|--------|
| ① | 写一篇本周发朋友圈/公众号的内容 | 需要做内容获客的 |
| ② | 整理一份客户常问问题 + AI回答模板 | 客服压力大的 |
| ③ | 做一个产品的AI销售话术 | 做销售的 |
| ④ | 用AI帮你分析一条竞品的内容 | 做市场的 |
| ⑤ | 把你的经验整理成一份"新人培训清单" | 带团队的 |
| ⑥ | 自定义：带一个你自己的真实任务 | 所有 |

**流程：**
1. 选任务 + 写提示词（5min）
2. AI出第一版（10min）
3. 自己改 + 让AI再改 → 循环3轮（60min）
4. 导师1v1巡场指导（全程）
5. 最后15min：每人展示最终作品（投影到大屏）

### 茶歇 (15:45-16:00, 15min)

---

### 模块六：你的AI资产系统 (16:00-16:30, 30min)
**比例：讲40% + 演示60%**

**讲（10min）：今天写了5个提示词，下个月全忘了怎么办？**

- 收藏夹没用：存了不看、看了找不到、找到了不会用
- 资产库有用：分类 + 标签 + 场景 → 要用时秒搜到

**演示（20min）：Zeno的AI资产库长什么样**

现场打开一个真实资产库，演示三个动作：
1. 把今天写的最好的提示词存进去
2. 给提示词加标签（如"客户回复""朋友圈""卖点提炼"）
3. 搜一下：想找一个"朋友圈"相关的提示词，3秒找到

**给模板：极简"我的AI资产库"模板**

```
📁 我的AI资产库
├── 📝 提示词库
│   ├── 客户沟通类
│   ├── 内容创作类
│   ├── 销售辅助类
│   └── 整理分析类
├── 📸 好结果截图
└── 💡 使用心得（一句话就行）
```

工具选择：飞书文档 / 微信收藏夹 / 手机备忘录，哪个顺手用哪个。

---

### 模块七：结营行动 (16:30-17:00, 30min)

**环节1：每人1分钟复盘 (15min)**
- 我今天最大的收获是什么？
- 我回去第一周要做什么？

**环节2：导师反馈 (5min)**
- 逐一确认：你承诺的动作，小到不可能失败吗？
- 如果太宏大，帮缩到最小可执行单位

**环节3：发"课后第一动作"卡片 (5min)**
- 实物卡片，质感好，写上学员自己的承诺
- 反面印提示词四要素速查表
- 拍照留念

**环节4：建7天行动群 (5min)**
- 群规则：
  - 每天发一条：今天用AI做了什么（哪怕是"写了一句话"）
  - 连续3天不发言 → 发红包
  - 7天后群解散或升级到进阶群
- 布置Day1任务："把你今天写的提示词再跑一次，截图发群里"

## 课程核心观点卡（讲师备忘）

以下观点贯穿全天，在对应模块自然带出，不单独讲：

- **AI不是魔法，是工具** → 模块一
- **不要学工具，要学AI思维** → 模块二
- **提示词不是"命令"，是"教AI你的语言"** → 模块三
- **AI能做70分就值得用，必须95分的先别用** → 模块四
- **今天做的这个作品，就是你的第一个资产** → 模块五
- **收藏夹是坟墓，资产库是武器库** → 模块六
- **小到不可能失败的动作，才可能持续** → 模块七
