【投屏显示：提示词四要素】

```
┌─────────────────────────────────────────┐
│             提示词四要素                  │
│         Zeno踩了上百个坑总结的            │
├────────────┬────────────────────────────┤
│ 1. 角色     │ 你是谁、让AI扮演谁          │
```

【指着左边截图】

你看我最早写的提示词——四要素只有"任务"一个。"帮我写一段装修介绍。"

【指着右边截图】

再看这个。四要素全了——

- 角色：我是一个做了十几年南宁本地装修的工头
- 任务：帮我写一段业务介绍
- 约束：口语化，不要广告腔，像跟朋友聊天，100字以内
- 输出：一段话

同一个AI，同样的任务。四要素齐全的效果是好5倍——这是我自己实测的数据。

> 📍 坑⑤（Z-49）：AI完美主义——过度迭代

但是注意一个坑。

【投屏：一张图——改了8轮的文案迭代记录，每一轮只比以前好一点点】

看到没有？这是我踩过的最大的坑——

有次让AI改一段文案，改了8轮。

第一轮→第二轮，提升很明显。第二轮→第三轮，还不错。第三轮→第四轮……变化已经很小了。到第八轮，跟第七轮几乎一模一样。

我花了2个小时。出来的东西，我自己写只要20分钟。

**AI迭代的拐点在第3-4轮。超过这个点，人工接手比继续让AI改更快。**

所以今天的实战环节，我们就定一个规则——每个任务最多改3轮。3轮之后，不管出来什么样，你自己动手改。

上午你们学会了怎么让AI说人话。下午我们要做一件更狠的事——让AI嵌入你的生意。

大多数人来学AI，第一个问题是："AI能做什么？"

这是错误的问题。

正确的问题是：**"我的生意里，什么最费时间？"**

【发"时间黑洞清单"——纸质，人手一张】

来，每人拿一张。上面有七件事，你觉得费时间的就打勾。

【投屏：AI切口四问】

```
这个任务AI能做70分就值得用AI。
必须做到95分的，先别用AI。

四问判断法：
━━━━━━━━━━━━━━━━━━━━━━
1. 这件事有套路吗？
   有套路 → AI能做
   没套路 → 别用AI

2. 这件事需要我的独特判断吗？
   不需要 → AI能做
   需要 → 你做判断，AI只做辅助

3. 这件事做错了代价大吗？
   不大 → 放手让AI做
   大 → AI出初稿，你来审

4. AI做完我改一下能用吗？
   能 → 马上用
   不能 → 换一个任务
```

来，现场试一个。

【从白板上选一个学员的时间黑洞——比如"做报价"】

**第一问：做报价这件事有套路吗？**

**第二问：做报价需要你的独特判断吗？**

"需要——有些项目要不要加、利润放几个点、客户好不好说话。"

→ 判断你做，格式和计算AI做。

**第三问：做报价做错了代价大吗？**

"大。"

→ AI出初稿，你审。

**第四问：AI做完你改一下能用吗？**

"能。AI算好材料费人工费，我调一下利润点，加一些说明，就能发给客户。"

→ **马上用。**
