# 星火者共同体

> 当前定义：小规模付费实践共同体。
> 长期方向：AI 时代 OPC 一人公司的分布式协作网络。
> 核心交付：角色清晰、经验资产、真实行动、项目复盘和可信协作。

## 在资产库中的位置

星火者是角色经营知识体系的现实验证场，不是资料仓库，也不是内容结构化系统的替代品。每位成员以一个真实角色运行小闭环：

```text
角色 → 本期问题 → 7 天行动 → 结果证据
→ 可复用资产 → 同伴试用 / 项目检验 → 复盘边界
```

成员原始记录默认留在授权范围内；对外发布或回流赞诺内容资产库前，必须脱敏并获得本人授权。回流内容应注明来源、授权状态和能证明 / 不能证明的范围。

## 角色知识体系交付

每位成员进入共同体后，逐步建立：

1. 当前角色与六个月目标。
2. 当前最重要的真实问题。
3. 已有技能、经验证据与能力缺口。
4. 可向其他成员提供的价值和当前所需。
5. 一个可验证的最小产品、服务或项目。
6. 至少一份复盘、案例、清单、SOP 或工具资产。

执行模板统一使用 `../内容结构化系统/07-模板库/赞诺角色经营画布.md`。首期先按 30 天运行一个最小闭环，不要求成员一次搭完全部知识。

完成后的复盘、案例或工具可以回到 `../内容结构化系统/01-原始素材区/` 登记并加工；不要直接把未经核验的成员分享写成赞诺方法论。

## 运营原则

- 读书和课程只是输入，行动、资产和协作才是交付。
- 不承诺赚钱、项目、客户、就业或投资结果。
- 成员的案例和复盘对外使用前，必须脱敏并获得本人授权。
- 先用小项目和书面边界建立信用，再谈长期协作。

`归档/` 保留 V1.0、V2.0 和 V2.1 的历史手册，用于复盘演变过程，不作当前运营依据。
