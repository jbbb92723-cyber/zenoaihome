# 星火者共同体

> 当前定义：申请制、8-10 人、90 天的付费实践共同体。
> 当前任务：验证成员能否通过真实问题、案例复盘和有限连接，完成一次原本难以独自完成的行动、连接或复盘。
> 长期方向：只有当前验证成立后，才讨论长期协作网络。

## 在资产库中的位置

星火者是赞诺公开实践的共同体验证场，不是资料仓库、派单群或公司服务折扣包。每位成员围绕一件真实事情运行最小闭环：

```text
正在做的事 → 90 天目标 → 当前问题 → 下一步行动
→ 结果证据 → 复盘 → 是否形成连接或协作
```

成员原始记录默认留在授权范围内。对外发布或回流赞诺内容资产库前，必须脱敏并获得本人授权，同时注明来源、授权状态和证据边界。

## 首期交付结构

1. 每月一次真实问题工作会。
2. 每月一次案例共读与复盘。
3. 每位成员建立一张实践档案。
4. 每位成员可提出一次有上下文的连接请求。
5. 有合适条件时提供共燃项目机会，但不保证数量和结果。
6. 90 天进行结营复盘。

## 商业边界

- 会员费只对应共同体固定交付，不包含赞诺个人咨询时长。
- 装修、AI 培训、知识库、工作流、智能体和网站等服务，由广西赞诺数智科技有限公司单独报价、签约和结算。
- 成员参与商业项目时，另行确认角色、工作量、报酬、责任、保密与知识产权。
- 不承诺赚钱、项目、客户、就业、投资或分润结果。
- 不提前承诺续费价格、永久锁价或年度会员制度。

## 首期验证数据

- 付费成员数与 30 天有效参与率
- 每月活动实际参与人数
- 完成实践档案、分享或复盘的人数
- 有上下文的连接请求与实际介绍次数
- 成员之间启动的协作次数
- 退款与退出原因
- 主理人每周实际投入时间
- 结营后愿意继续参与的比例
