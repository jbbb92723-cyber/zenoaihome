# 星火者品牌视觉规范 V1.0

## 1. 品牌定义

**正式名称：** 星火者创业实践共同体  
**对外简称：** 星火者  
**品牌背书：** ZENO赞诺发起  
**核心表达：** 独立，但不孤立。  
**设计概念：** 同行成火

星火者不是聊天群、培训班、派单平台或身份俱乐部。视觉需要表达独立实践者因为真实问题而相遇，在行动、反馈、连接和复盘中形成新的推进。

## 2. 标志构形

图形由三部分组成：

1. 左右两条墨黑路径代表保持主体性的独立行动者。
2. 中央朱砂形代表因真实协作形成的火种。
3. 两条路径之间的向上负形代表共同推进，而不是被组织吞没。

图形不是对火焰的直接描摹。禁止额外添加五角星、AI 闪光、人物头像、握手或网络节点。

## 3. 标志层级

| 版本 | 使用场景 |
|---|---|
| 图形标 | 微信头像、网站图标、胸牌角标、小尺寸识别 |
| 紧凑横版 | 网站导航、活动海报、社交媒体图片 |
| 标准横版 | 正式介绍、招募材料、合作文件、PPT 封面 |
| 反白版 | 深色背景、视频片尾、深色屏幕 |
| 单色版 | 黑白打印、雕刻、烫印、印章等受限工艺 |

“ZENO赞诺发起”是背书，不是星火者主名称。空间不足时优先保留“星火者”和“创业实践共同体”，背书可以移到页脚。

## 4. 标准色

| 名称 | 色值 | 用途 |
|---|---|---|
| 墨黑 | `#111111` | 主图形、主文字、深色背景 |
| 朱砂 | `#9E2B25` | 火种与关键识别，不超过画面约 15% |
| 暗色朱砂适配 | `#C9504A` | 仅用于深色背景上的火种 |
| 暖白 | `#F4F1E8` | 主要浅色背景与反白图形 |
| 纸灰 | `#D9D3C4` | 分隔线、辅助底色 |
| 辅助灰 | `#777066` | 次级说明文字 |

禁止给标志增加渐变、发光、金属质感或投影。不得把整张物料做成朱砂色，以免变成培训机构或赛事视觉。

## 5. 字体

- 中文品牌字：`Noto Sans SC Bold`。
- 中文副标与正文：`Noto Sans SC Medium / Regular`。
- 办公环境缺少字体时：使用微软雅黑作为替代。

品牌名称不使用书法字、卡通字或仿古印章字。星火者需要有东方克制感，但首先应当清楚、现代、可信。

## 6. 安全空间与最小尺寸

- 安全空间以中央火种宽度的一半作为 `X`，标志四周至少保留 `1X`。
- 图形标数字端最小建议为 `24px`，小于 `32px` 时只使用图形，不附带文字。
- 紧凑横版数字端最小建议宽度为 `140px`。
- 图形标印刷端最小建议为 `8mm`，标准横版最小建议宽度为 `35mm`。

## 7. 使用禁忌

- 不拉伸、不压扁、不倾斜标志。
- 不改变三个构形之间的位置和比例。
- 不把火种改成普通五角星或常见 AI 四角闪光。
- 不给标志加圆形徽章、盾牌、麦穗和口号环绕。
- 不把“社区”“社群”“俱乐部”写入主标。
- 不把 `ZENO赞诺` 与“星火者”做成同等字号。
