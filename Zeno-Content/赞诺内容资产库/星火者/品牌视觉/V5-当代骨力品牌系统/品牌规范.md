# 星火者品牌视觉规范 V5

## 当前状态

本版以已选择的“当代骨力”为基础继续精修，是进入官网和正式物料前的定稿提案。V1-V4 保留为设计过程，不再作为当前候选。

## 品牌层级

- 主名称：`星火者`
- 描述：`创业实践共同体`
- 发起关系：`ZENO赞诺 发起`
- 法定服务主体：广西赞诺数智科技有限公司，仅在合同、收款、开票和正式机构信息中说明，不塞进共同体 Logo。

## 设计逻辑

主标保留现代黑体的清楚与骨力，重新控制三个字的宽度、字距和基线。“火”的中轴向上延伸，并以唯一一处朱砂收笔，成为品牌记忆点。它不是普通火焰、五角星或网络节点，而是从汉字本身长出的行动标记。

与 `ZENO赞诺` 企业母标共享骨纸、炭黑和朱砂，形成同一品牌家族；两者的记忆点分别落在 `O` 的判断笔画和“火”的行动中轴，不使用同一个图形强行套版。

## 语言与视觉原则

品牌板中的原则句为：

> 独立行动，有边界地连接。

它用于解释视觉与共同体关系，不替代当前运营真源。对外描述仍以“申请制、8-10 人、90 天的创业实践共同体”为准。

## 文件选择

| 场景 | 文件 |
|---|---|
| 官网星火者页面、公众号文章、普通海报 | `星火者-标准组合-彩色.svg` |
| 只需要名称、尺寸较小 | `星火者-主标-彩色.svg` |
| 与赞诺个人品牌一起出现 | `星火者-ZENO赞诺背书-彩色.svg` |
| 深色背景 | 对应 `反白.svg` |
| 纯黑印刷、刻字、单色喷绘 | 对应 `单色.svg` |
| 微信头像、favicon、活动角标 | `星火者-火字印记.svg` 或 `星火者-头像版.svg` |

标准组合建议不小于 `220px` 宽；主标建议不小于 `96px` 宽；火字辅助印记建议不小于 `24px`。尺寸更小时，优先保留主名称，不强行显示描述和发起关系。

## 色彩

- 炭黑：`#111111`
- 骨纸：`#F4F1E8`
- 朱砂：`#9E2B25`

朱砂只用于“火”的中轴。不得把三个字全部改红，也不得增加橙黄渐变、发光或火焰纹理。

## 禁止

- 不添加五角星、普通火焰、人物、握手、网络节点或仿古印章。
- 不把辅助火字印记当作所有场景的唯一 Logo。
- 不拉伸、压扁、描边、投影或改变字距。
- 不写成“星火者社群”“星火者俱乐部”或未经验证的“分布式协作网络”。
- 不在品牌视觉中承诺客户、项目、收入、投资或分润结果。
