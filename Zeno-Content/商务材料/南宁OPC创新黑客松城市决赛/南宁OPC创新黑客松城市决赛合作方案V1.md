# 南宁 OPC 创新黑客松城市决赛合作方案

## AI+东盟场景与传统产业微创新验证站

**合作提案方：广西赞诺数智科技有限公司**<br>
**本地协作载体：南A中心东盟谷 OPC 社区**<br>
**创业者实践网络：星火者共同体**<br>
**方案版本：V1.0 讨论稿｜2026 年 8 月 21 日**

> 本方案根据《OPC 创新黑客松大赛（城市决赛）赛事合作方案》进行南宁本地化策划。OPC 圈赛事 IP、联合主办方、全国数据、总赛程、奖项、晋级名额及相关品牌使用，均须以组委会正式授权和最终赛事文件为准。

# 一、方案摘要

## 1.1 南宁城市站的一句话定位

> **用一场面向一人公司和小型团队的创新赛事，把 AI 创意放进南宁真实的东盟商贸、传统产业、园区服务和城市消费场景里，完成从想法、原型到项目决策的第一次验证。**

全国赛事的核心是发现项目，南宁城市站要多完成一步：**让项目找到真实问题，让企业找到可试用的解决方案。**

## 1.2 建议名称

**南宁 OPC 创新黑客松城市决赛**<br>
副标题：**AI+东盟场景与传统产业微创新验证站**

副标题不是另起一个赛事品牌，而是南宁城市站的地方化表达。最终名称、Logo、宣传口径和联合主办排序，须由 OPC 圈组委会确认。

## 1.3 本地化后的三层价值

| 层次 | 南宁城市站要做什么 | 形成的结果 |
|---|---|---|
| 城市产业微创新引擎 | 从企业、园区、社区和高校征集真实问题 | 一份脱敏的《南宁 AI 城市场景需求清单》 |
| 个体商业验证加速器 | 让个人创新者和 2-5 人团队用最小原型验证价值 | 一批有测试记录、场景负责人和下一步决策的项目 |
| OPC 生态网络节点 | 把赛事参与者、企业需求方和专业协作者连接起来 | 南宁项目台账、赛后 90 天跟踪和可复用合作机制 |

## 1.4 推荐采用的合作结构

本方案推荐采用“全国统筹 + 南宁本地执行 + 赛后项目交付”的三层结构：

1. **OPC 圈组委会**负责赛事 IP、全国征集、统一赛制、评审和全国晋级。
2. **广西赞诺数智科技有限公司**负责南宁城市站的本地项目管理、企业场景运营、商务协调和赛后交付组织。
3. **南A中心东盟谷 OPC 社区**提供园区、场地、企业与创业者连接入口，具体资源以书面确认结果为准。
4. **星火者共同体**作为人才发现、实践训练、能力验证和协作信用沉淀机制，不作为赛事收款、签约、派单或交付主体。
5. **赞诺企业 AI FDE 联合交付组**在赛后承接场景工作坊、验证冲刺和生产建设，所有项目另行报价、签约和验收。

## 1.5 本次合作希望谈成的不是一场活动

南宁城市站应以以下四件长期资产作为验收方向：

- 一份经过需求方确认、脱敏并标注状态的南宁 AI 场景清单。
- 一套“企业问题预审 - 项目验证 - 场景试用 - 赛后跟踪”的项目管线。
- 一组经过赛事展示和能力核验的个人创新者、小团队与专业协作者。
- 一份能够被园区、企业和下一届赛事继续使用的《南宁 OPC 创新项目复盘报告》。

赛事热度是过程指标，真实场景、项目决策和后续交付才是结果指标。

# 二、从全国总纲到南宁方案

## 2.1 全国机制与南宁增量

| 全国总纲 | 南宁本地化动作 | 南宁新增价值 |
|---|---|---|
| 线上项目征集 | OPC 圈全国征集，南宁同步发动本地企业、园区、高校和社区 | 提高南宁项目密度，避免只靠线上报名 |
| 城市决赛 | 保留统一赛道、路演、答辩和评分 | 保证全国可比性 |
| 场景对接 | 赛前发布南宁城市场景需求清单，现场安排需求发布和洽谈 | 把路演从展示变成问题匹配 |
| 全国晋级 | 按组委会统一名额和规则执行 | 让南宁项目获得全国曝光机会，但不提前承诺晋级 |
| 赛后孵化 | 由赞诺公司组织 FDE 预审、工作坊、验证冲刺和项目台账 | 让赛事成果进入可验收的下一阶段 |
| OPC 生态网络 | 依托东盟谷和星火者持续连接创业者与需求方 | 形成城市节点，而不是一次性会务项目 |

## 2.2 南宁不复制的部分

南宁不把赛事做成单纯的 AI 工具展示会，也不以“参赛即获订单”“获奖即获投资”“加入共同体即有派单”为宣传逻辑。地方化应坚持三个判断：

- 项目是否解决一个能被说明、观察和验收的真实任务。
- 场景需求方是否愿意投入时间、样本和责任人参与验证。
- 赛后是否有明确的 Go、调整或 No-Go 结论，而不是停留在颁奖和合影。

# 三、为什么是南宁

## 3.1 南宁的场景优势

南宁适合承接这类城市站，主要不是因为需要再增加一个创业活动，而是因为本地同时具备以下场景组合：

| 场景基础 | 可转化的赛事命题 |
|---|---|
| 中国-东盟商贸与会展连接 | 多语言内容、本地化营销、跨境客户服务、展会线索整理 |
| 传统企业和中小企业密集 | 报价核对、合同附件整理、知识检索、客服辅助和经营台账 |
| 园区、社区和创业服务组织 | 入驻服务、政策资料问答、活动运营、创业项目跟踪 |
| 文旅、餐饮、零售和城市消费 | 门店运营、内容生产、客户反馈分析、活动转化和供应链协同 |
| 高校、青年开发者和内容创作者 | AI 应用原型、交互体验、游戏与内容创新、校园创业项目 |
| 面向东盟的人才与跨境服务基础 | 翻译、本地文化适配、市场研究、远程专业服务和跨境协作 |

上述是适合征集和验证的方向，不等于南宁政府、园区或企业已经承诺提供对应项目。每个场景必须重新完成需求登记和授权确认。

## 3.2 南宁城市站的主张

> **南宁不只是举办一场比赛，而是把城市变成一间开放的 AI 场景实验室。**

这句话对外使用前，须根据主办方和合作城市的最终口径复核。正式材料中建议使用更稳妥的表达：

> **以南宁真实产业与城市服务场景为入口，推动 AI 项目从展示走向验证。**

# 四、赛事目标与建议指标

## 4.1 目标分四层

### 目标 A：找到人

吸引正在做具体事情的个人创新者、开发者、设计师、传统行业实践者、学生和 2-5 人小型团队。

### 目标 B：找到问题

从企业、园区、社区、学校和城市服务机构中征集可脱敏、可解释、可试用的真实任务。

### 目标 C：完成验证

让项目至少完成一次可运行演示、场景匹配、评审反馈和下一步决策。

### 目标 D：形成后续

把具备前提的项目导入 90 天跟踪，不把跟踪写成无条件孵化、投资或订单承诺。

## 4.2 建议目标值

以下是南宁城市站的运营目标，不是对外结果保证，最终应在预算、时间和组委会名额确认后锁定。

| 指标 | 建议目标 | 口径 |
|---|---:|---|
| 有效报名项目 | 80-120 个 | 完成资料、赛道和项目状态登记 |
| 线上复赛项目 | 30-50 个 | 完成材料初审或线上演示 |
| 现场决赛项目 | 15-20 个 | 推荐的单日可执行规模；如组委会要求 30-50 个，须增加舞台或天数 |
| 城市场景需求 | 10-15 个 | 有需求方、负责人、问题和资料边界 |
| 现场企业/机构 | 30-50 家 | 完成签到且至少参与一场需求或项目交流 |
| 场景洽谈记录 | 20-40 条 | 有双方同意的下一步，不把交换名片算成项目 |
| 进入赛后预审 | 8-12 个 | 项目方和需求方都愿意补充材料 |
| 完成验证冲刺 | 2-4 个 | 需另行签约、付款或取得专项资助 |
| 脱敏案例/复盘 | 2-4 份 | 取得对外发布授权后才能公开 |

## 4.3 关键验收原则

不以报名数量和现场人流单独验收。城市站至少应同时交付：

- 项目台账、需求台账和洽谈台账。
- 评审记录、晋级记录和异议处理记录。
- 赛后每个项目的状态：继续、调整、暂停或 No-Go。
- 费用使用与实际交付清单。
- 对外案例的授权与脱敏记录。

# 五、赛道与南宁命题

## 5.1 保留全国统一赛道

南宁城市站原则上保留总纲的 3 个主赛道和 2 个特别赛道：

1. **AI for Business**：面向企业经营、生产、销售、服务与管理。
2. **AI for Life**：面向生活方式、城市服务、教育、健康和消费体验。
3. **AI for Creation**：面向内容、设计、游戏、文化和创意表达。
4. **知乎校园新锐**：是否保留、品牌和规则以正式合作确认为准。
5. **Unity AI 游戏**：是否保留、技术要求和品牌使用以正式合作确认为准。

## 5.2 增加南宁场景命题

地方命题不与全国赛道并列为新的强制赛道，而作为城市需求清单和现场对接主题：

| 南宁命题 | 适合征集的问题 | 需求方类型 |
|---|---|---|
| AI+东盟商贸与跨境服务 | 多语言商品资料、客户问答、市场资料整理、展会线索跟进 | 外贸企业、跨境服务商、园区企业 |
| AI+传统产业经营与交付 | 报价核对、合同附件审查、施工与项目记录、培训资料检索 | 装修、工程、制造、服务企业 |
| AI+文旅、会展与城市消费 | 活动内容、游客问答、门店反馈、会员和复购运营 | 文旅、会展、餐饮、零售机构 |
| AI+园区、社区和创业服务 | 入驻问答、政策资料导航、活动运营、项目台账 | 园区、社区、孵化器、服务机构 |
| AI+内容创意与城市传播 | 城市内容本地化、短视频素材整理、视觉与交互原型 | 媒体、品牌、设计师、创作者 |

## 5.3 命题入选标准

一个需求只有同时满足以下条件，才进入公开场景清单：

- 能说出当前由谁做、输入是什么、输出是什么。
- 有真实但可脱敏的样本或资料路径。
- 有业务责任人和试用人，而不是只有转述人。
- 能定义一个最小验证结果。
- 不要求参赛者接触未授权的个人信息、商业秘密或生产权限。
- 不把医疗、法律、财务、安全等高风险判断交给模型自动完成。

不满足条件的需求，可以进入“待澄清池”，但不能包装成已经开放的企业命题。

# 六、参赛者招募与筛选

## 6.1 招募对象

- 有真实行业经验、希望用 AI 改造自己工作的个人实践者。
- 2-5 人小型团队和成立 3 年以内的企业。
- 产品经理、工程师、设计师、研究者、内容创作者和学生团队。
- 传统行业从业者与技术协作者组成的跨专业小队。
- 能把 AI 用进具体任务，而不只是展示工具的人。

## 6.2 南宁招募渠道

| 渠道 | 动作 | 负责方建议 |
|---|---|---|
| OPC 圈全国平台 | 全国项目招募、赛制解释、报名入口 | OPC 圈组委会 |
| 南A中心东盟谷 | 园区企业、入驻创业者、活动和场地传播 | 东盟谷运营方 |
| 南宁高校 | 青年开发者、创意和校园项目 | 高校合作联系人 |
| 本地企业协会与商协会 | 需求方和行业参赛者双向招募 | 本地执行团队 |
| 星火者共同体 | 真实实践者、行业顾问、复盘志愿者 | 星火者运营方 |
| 公众号、小红书、视频号等 | 发布真实问题和项目故事，不做模板化“精准获客” | 内容运营团队 |

## 6.3 筛选不是筛“会不会 AI”

项目报名表建议只保留会改变评审判断的信息：

1. 解决什么具体问题，谁正在为此付出时间或成本。
2. 当前怎么做，已经有什么材料、流程或用户反馈。
3. AI 在哪一个环节介入，哪些环节仍由人负责。
4. 已有原型、样本、用户或订单证据是什么。
5. 计划在比赛期间验证哪个关键假设。
6. 项目有哪些数据、权限、知识产权或合规限制。
7. 需要哪一种场景方、技术方或行业方帮助。

# 七、城市场景需求征集机制

## 7.1 场景卡一页模板

每个场景进入台账前，至少填写以下字段：

| 字段 | 说明 |
|---|---|
| 需求方 | 企业/机构全称、行业、联系人和角色 |
| 原始问题 | 保留需求方原话，不先替对方改成“AI 需求” |
| 当前流程 | 谁在什么时间、用什么资料完成什么工作 |
| 频率与基线 | 每周/月次数、耗时、返工、等待或错误记录 |
| 期望变化 | 希望减少什么、改善什么，不直接承诺百分比 |
| 可提供样本 | 样本类型、数量、脱敏方式和可使用期限 |
| 数据边界 | 可公开、仅闭门、需 NDA、不可外部调用 |
| 试用条件 | 谁试用、在哪里试用、什么算完成 |
| 需求状态 | 待澄清、已确认、可公开、已匹配、已暂停 |

## 7.2 三种开放等级

### A 级：公开命题

可以公开企业类型、问题摘要和参赛方向，不公开敏感资料。适合用于报名招募和线上传播。

### B 级：闭门命题

只向通过初筛的项目方、评审和合作方开放，需签署保密或资料使用确认。

### C 级：企业内部试点

只在赛后由需求方与项目方单独协商，另行签约，不作为赛事方对外承诺。

## 7.3 场景对接会的结构

建议设置 90-120 分钟，不做泛泛的“AI 交流”：

1. 需求方发布 5-8 个经过初审的场景，每个 3 分钟。
2. 项目方按场景卡选择 1-2 个最匹配的问题。
3. 现场进行小组洽谈，每组明确输入、输出、样本、负责人和下一步。
4. 结束前登记“继续收集资料、工作坊、验证报价、暂停”四种状态。

# 八、赛事流程与时间建议

## 8.1 总体流程

| 阶段 | 建议时间 | 核心动作 | 主要产出 |
|---|---|---|---|
| 0. 立项确认 | T-8 至 T-6 周 | 确认授权、预算、场地、主体、赛程和责任 | 合作确认书、RACI、预算表 |
| 1. 场景征集 | T-6 至 T-4 周 | 走访企业、园区、社区和高校，形成需求池 | 场景卡、企业名单、传播素材 |
| 2. 项目招募 | T-5 至 T-2 周 | 全国与本地同步报名、答疑、内容传播 | 报名项目台账 |
| 3. 线上初筛 | T-2 至 T-1 周 | 材料评审、线上演示、项目补资料 | 复赛名单、评审记录 |
| 4. 城市决赛 | T 日 | 路演、答辩、场景对接、闭门洽谈和颁奖 | 评审结果、洽谈台账、晋级名单 |
| 5. 赛后 90 天 | T+1 至 T+90 天 | 预审、工作坊、验证冲刺、复盘 | 项目状态和成效报告 |

## 8.2 2026 年日历建议

附件总纲提出的“8 月底启动、9 月 20 日报名截止、9-10 月城市决赛、11 月总决赛、12 月起孵化”可作为建议节奏，但当前不能视为南宁已确定日程。

建议先按以下节点与组委会校准：

- 2026 年 8 月下旬：完成合作主体、授权、预算和城市站日期确认。
- 2026 年 9 月上旬：完成第一批场景卡和项目招募发布。
- 2026 年 9 月 20 日前后：按全国口径确认报名截止，以组委会系统为准。
- 2026 年 9 月下旬至 10 月：完成南宁线上复赛和城市决赛。
- 2026 年 11 月：按全国总决赛安排完成晋级项目交接。
- 2026 年 12 月起：建立南宁赛后项目台账，进入 90 天跟踪。

## 8.3 现场规模的执行判断

若每个项目安排 8 分钟路演 + 5 分钟答辩，30 个项目已需要约 6.5 小时纯评审时间，50 个项目将超过单日合理承载。

因此建议向组委会确认以下两种方案之一：

| 方案 | 适用方式 |
|---|---|
| 单日精决赛 | 线上复赛 30-50 个，现场决赛 15-20 个，适合企业洽谈和媒体传播 |
| 双舞台/两日城市站 | 现场仍保持 30-50 个项目，但按赛道分流，增加主持、技术、评审和会务成本 |

南宁本地不擅自修改全国晋级和评分规则，先把执行成本和体验风险透明化。

# 九、城市决赛现场设计

## 9.1 空间分区

建议场地至少形成六个区域：

1. **主舞台**：路演、答辩、评审和颁奖。
2. **场景发布区**：企业和机构发布真实问题。
3. **项目展示区**：可试用原型、海报和项目资料。
4. **闭门洽谈区**：需求方与项目方一对一或小组交流。
5. **评审与资料区**：评分、材料、授权和项目状态登记。
6. **媒体与记录区**：经授权的摄影、采访和案例记录。

## 9.2 推荐的一日流程

| 时间 | 环节 | 重点 |
|---|---|---|
| 09:00-09:30 | 签到与项目设备检查 | 确认演示、资料、授权和候场顺序 |
| 09:30-09:50 | 开场与赛制说明 | 说明评审、责任边界和场景对接规则 |
| 09:50-10:30 | 南宁场景发布 | 需求方发布 5-8 个经过初审的场景 |
| 10:40-12:20 | 第一组项目路演 | 每个项目按统一时长执行 |
| 13:30-15:10 | 第二组项目路演 | 评审同步记录证据与疑问 |
| 15:20-16:30 | 项目展示与闭门洽谈 | 形成下一步状态，不现场承诺订单 |
| 16:30-17:10 | 评审合议 | 核对评分、利益冲突和晋级规则 |
| 17:10-17:40 | 颁奖与项目点评 | 只公布已确认的结果和奖项 |
| 17:40-18:00 | 赛后说明 | 说明 90 天跟踪申请与资料交接 |

## 9.3 现场必须留下的记录

- 项目编号、参赛主体、路演版本和演示环境。
- 评委评分表与关键意见。
- 需求方与项目方的洽谈登记。
- 项目是否同意赛后联系、是否需要 NDA、下一次会议时间。
- 影像、Logo、项目截图和案例使用授权。

# 十、评审、奖项与赋能

## 10.1 评审标准

原则上沿用附件总纲：

| 维度 | 权重 | 南宁评审关注点 |
|---|---:|---|
| 商业模式与可行性 | 30% | 谁付费、为什么现在付费、如何交付和持续经营 |
| 用户价值 | 25% | 是否解决真实问题，使用人是否愿意继续使用 |
| 场景落地与完成度 | 20% | 是否有样本、原型、测试记录和责任人 |
| 技术实现 | 15% | 技术路径、稳定性、数据和人工复核边界 |
| 演示体验与表达 | 10% | 是否清楚展示输入、过程、输出和限制 |

评委人数、评审回避、晋级数量和奖项设置以组委会最终规则为准。推荐评审组成：企业需求方 2 人、行业专家 1-2 人、产品/工程专家 1-2 人、投资或创业服务观察员 1 人。

## 10.2 奖项不要只奖励“最会讲”

可在全国统一奖项之外，申请设置南宁城市单项奖：

- 东盟场景适配奖。
- 传统产业微创新奖。
- 最小验证价值奖。
- 最佳真实问题回应奖。
- 最佳人机协作实践奖。

单项奖名称、奖品、奖金和评选权属必须经组委会与赞助方确认。任何奖项不自动等于订单、投资、政策或采购资格。

## 10.3 赛后赋能权益

建议把权益分为“确定交付”和“申请制机会”：

| 确定交付 | 申请制机会 |
|---|---|
| 评审反馈、项目材料归档、赛后状态回访 | 与企业场景方进一步洽谈 |
| 一次赛后项目预审说明会 | 场景工作坊、验证冲刺或试点报价 |
| 项目复盘模板和资料清单 | 进入星火者实践活动或专项协作 |
| 晋级项目交接和组委会要求的资料支持 | 投资、算力、政策、采购或媒体机会 |

这样既能给参赛者明确价值，也不提前承诺资源结果。

# 十一、赛后 90 天项目孵化路径

## 11.1 赛后不是免费开发

赛事结束后，项目进入“证据整理和下一步判断”，而不是自动获得免费开发、订单或投资。只有项目方、需求方、交付团队和预算条件同时成立，才进入付费项目。

## 11.2 90 天路径

| 阶段 | 时间 | 负责方 | 产出 |
|---|---|---|---|
| 赛后登记 | T+1 至 T+7 天 | 赞诺公司 | 项目状态、联系人、授权和资料清单 |
| 场景预审 | T+8 至 T+15 天 | FDE 预审组 | 一页问题卡、是否适合验证的判断 |
| 场景工作坊 | T+16 至 T+30 天 | FDE 小队与企业 | 当前流程、目标、非目标和验证方案 |
| 验证冲刺 | T+31 至 T+45 天 | 赞诺 FDE 联合交付组 | 受控原型、测试、价值测算和 Go/No-Go |
| 试点或停止 | T+46 至 T+75 天 | 客户与项目团队 | 试点范围、变更或 No-Go 记录 |
| 复盘与报告 | T+76 至 T+90 天 | 赞诺公司 | 90 天项目报告和后续建议 |

## 11.3 赛后服务产品建议

采用现有 FDE 交付体系的内部产品梯度，最终价格以实际范围、样本、部署、税费和 SOW 为准：

| 产品 | 内部参考价 | 适合阶段 | 核心产出 |
|---|---:|---|---|
| AI 场景工作坊 | ¥9,800 起 | 还没有选定第一场景 | 场景清单、优先级、问题卡和下一步 |
| FDE 验证冲刺 | ¥39,800-69,800 | 已有一个候选任务 | 10 个工作日、原型、测试、价值测算、Go/No-Go |
| 生产建设 | ¥128,000 起 | 验证结论成立 | 另签 SOW 的开发、集成、部署、培训与验收 |

上述服务由广西赞诺数智科技有限公司或明确的合作主体签约、收款和交付。星火者会员费不抵扣企业项目费用，会员身份不保证项目机会或收入。

## 12.2 广西赞诺数智科技有限公司

**承担：**本地执行、企业和园区连接、场景征集、项目台账、现场组织、商务协调、赛后 FDE 项目管理和报告。<br>

**提供：**场地、园区入口、企业连接、社区传播和本地活动资源，具体以运营方书面确认。<br>
**获得：**园区企业服务入口、城市创新活动内容、企业需求沉淀和社区影响力提升。

## 12.4 星火者共同体

**承担：**实践者招募、能力档案、复盘活动、有限连接和符合条件的项目协作。<br>

**获得：**赛事展示、评审反馈、项目对接和赛后申请机会。<br>
**承担：**如实说明能力和贡献，遵守数据、知识产权、保密和项目纪律，不把展示原型直接用于生产高风险决策。

标杆版不应只增加舞台和会务，而应增加企业试点、项目验证和可核验的后续交付。

# 十五、传播与内容策略

## 15.1 传播主线

不采用“精准获客”式恐惧营销和统一模板，而采用三条真实内容线：

1. **城市问题线**：南宁企业正在遇到什么具体工作问题。
2. **项目验证线**：参赛者怎样用原型、样本和测试证明一个假设。
3. **赛后复盘线**：什么项目继续、什么项目缩小、什么项目被判断为 No-Go。

## 15.2 内容栏目建议

| 栏目 | 例题 | 适合平台 |
|---|---|---|
| 南宁场景征集 | “一家外贸企业每天怎样整理东盟客户资料？” | 公众号、视频号、OPC 圈 |

内容发布前须完成项目、人物、数据、Logo 和案例授权。没有授权的项目只能使用匿名、抽象和经确认的描述。

# 十六、风险、合规与宣传边界

## 16.1 必须书面核验的事项

1. OPC 圈总纲中的注册创业者数量、城市数量、项目数量和社群数量。
2. 知乎、Unity 中国及其他机构的联合主办、协办或品牌合作关系。
3. 南宁市政府、人社、园区或任何部门是否作为主办、指导或支持单位。
4. 政策补贴、人才服务、绿色通道、政府采购优先权和算力资源。
5. 南A中心东盟谷提供的场地、免租、企业名单和对外背书口径。
6. 奖金、奖品、全国晋级名额、媒体传播和项目孵化权益。

## 16.2 不得对外承诺

- 获奖即获得订单、投资、算力、政策或采购资格。
- 加入星火者即获得客户、项目、收入或派单。
- 参赛项目一定进入生产、一定节省某个固定比例成本。
- 组委会或合作方为所有项目承担商业、技术、法律和数据责任。
- 未经客户授权公开其名称、Logo、数据、截图、金额和内部流程。

## 16.3 数据与知识产权

- 赛前优先使用脱敏、合成或公开资料。
- 真实企业资料进入模型、云服务、代码库或标注平台前，必须确认授权和服务条款。
- 参赛作品的既有资产、比赛期间产生的成果、第三方模型和开源代码分别登记。
- 项目案例对外发布必须获得单独授权，且说明实际贡献和验证边界。
- 赛事报名、照片、录音和联系方式的收集、使用、保存和删除应有隐私说明。

# 十九、建议向合作方提出的决策问题

第一次正式沟通只需要推动以下 8 个决定：

1. OPC 圈是否正式授权南宁城市站，授权主体是谁。
2. 南宁城市站采用单日精决赛还是双舞台/两日方案。
3. 哪个主体负责预算、合同、付款和发票。
4. 南A中心东盟谷是否提供场地、企业入口和现场资源，边界是什么。
5. 第一批 5-8 个企业场景由谁提供、谁承担资料授权责任。
6. 城市站预算采用基础验证版、标准城市版还是标杆城市版。
7. 赛后 90 天跟踪是否纳入城市站预算，还是由企业另行采购。
8. 哪些数据、品牌、奖项和政策口径可以公开，哪些只能内部使用。

# 二十、结论

南宁城市站最有价值的打法，不是把全国总纲换成一个南宁地名，而是把南宁的东盟商贸、传统产业、园区服务和城市消费场景变成可被创新者理解、可被企业试用、可被评审验证的问题。

建议最终以以下合作承诺作为谈判底稿：

> **OPC 圈提供全国赛事机制和项目入口；南A中心东盟谷提供南宁本地场景与社区连接；广西赞诺数智科技有限公司负责把需求组织成项目，把项目组织成可验收的验证；星火者共同体承载实践者和协作者的长期连接。赛事结束后，留下的不只是奖项，而是一套能继续运行的南宁项目台账和场景验证机制。**

这是一份合作讨论稿，不构成 OPC 圈、政府、园区、品牌方或任何企业已经作出的承诺。正式对外版本应在授权、预算、主体、时间、数据和品牌文件齐备后发布。
