# FDE 项目成本测算表

## 1. 使用规则

这份表用于报价前判断“这单做了会不会亏”。它不用于对外解释成本，也不承诺团队成员固定收入。

每个项目至少建立一份独立副本，采用同一口径记录：

- 对客收入按不含税口径测算。
- 人日成本按团队实际可接受的内部成本或分包报价填写，不用想象中的市场单价替代。
- 模型、API、云资源、差旅、外包、发票、退款和售后预留必须单列。
- 预计成本超过收入的 60% 时，优先缩小范围、提高价格或不承接。

## 2. 核心公式

| 指标 | 公式 |
|---|---|
| 不含税收入 | 含税合同额 ÷（1 + 适用税率） |
| 人力成本 | 角色人日 × 内部成本 / 分包人日价 |
| 直接交付成本 | 人力成本 + 第三方费用 + 差旅 + 项目专属采购 |
| 直接成本率 | 直接交付成本 ÷ 不含税收入 |
| 项目毛利 | 不含税收入 - 直接交付成本 |
| 项目毛利率 | 项目毛利 ÷ 不含税收入 |
| 预计净贡献 | 项目毛利 - 获客与商务成本 - 售后预留 - 税务 / 财务处理成本 |

内部试运行门槛：

- 外部硬成本原则上不超过不含税收入的 15%。
- 总直接交付成本原则上不超过不含税收入的 60%。
- 目标项目毛利率不低于 40%。
- 任何门槛未达到，都必须在报价评审中说明原因和补救动作。

## 4. 两档验证冲刺内部示例

以下只是首期预算演示，不能替代真实项目填表。

### 4.1 ¥39,800 档

适用于单一场景、单一部门、样本已整理、低风险验证，不包含生产部署。

| 成本项 | 假设 | 金额 |
|---|---|---:|
| FDE Lead | 2.5 人日 × ¥1,200 | ¥3,000 |
| 解决方案 / 产品 | 3.5 人日 × ¥1,200 | ¥4,200 |
| AI / 全栈工程 | 5 人日 × ¥1,500 | ¥7,500 |
| 质量复核 | 1.5 人日 × ¥1,000 | ¥1,500 |
| 项目管理与交接 | 1 人日 × ¥800 | ¥800 |
| 模型 / API / 云资源 | 预算 | ¥1,200 |
| 差旅与会议 | 预算 | ¥500 |
| 风险预留 | 预算 | ¥1,800 |
| **直接交付成本** | 13.5 人日左右 | **¥20,500** |
| **直接成本率** | ¥20,500 ÷ ¥39,800 | **51.5%** |
| **项目毛利** | ¥39,800 - ¥20,500 | **¥19,300** |
| **项目毛利率** | ¥19,300 ÷ ¥39,800 | **48.5%** |

这个价格成立的前提是客户资料已经可用，团队不承担大规模数据清洗、复杂接口、生产部署和无上限修改。

### 4.2 ¥69,800 档

适用于多个角色或资料源、需要轻量接口、数据处理、权限原型或成熟团队专项复核的验证。

| 成本项 | 假设 | 金额 |
|---|---|---:|
| FDE Lead | 3.5 人日 × ¥1,400 | ¥4,900 |
| 解决方案 / 产品 | 4.5 人日 × ¥1,400 | ¥6,300 |
| AI / 全栈工程 | 8 人日 × ¥1,800 | ¥14,400 |
| 行业 / 数据专家 | 2 人日 × ¥1,600 | ¥3,200 |
| 质量复核 | 2 人日 × ¥1,200 | ¥2,400 |
| 项目管理与交接 | 2 人日 × ¥1,000 | ¥2,000 |
| 模型 / API / 云资源 | 预算 | ¥2,000 |
| 差旅 / 第三方服务 | 预算 | ¥1,500 |
| 风险预留 | 预算 | ¥2,500 |
| **直接交付成本** | 22 人日左右 | **¥39,200** |
| **直接成本率** | ¥39,200 ÷ ¥69,800 | **56.2%** |
| **项目毛利** | ¥69,800 - ¥39,200 | **¥30,600** |
| **项目毛利率** | ¥30,600 ÷ ¥69,800 | **43.8%** |

这个价格成立的前提是只验证一个业务场景。若客户同时要求知识库、工作流、智能体、网站和培训，应拆分项目，而不是继续沿用此档价格。

## 5. 报价前红灯

出现以下任一情况，不能按示例价直接报价：

- 客户要求生产部署、私有化、等保、灾备或 7×24 运维。
- 真实数据需要大规模清洗、标注、迁移或人工校验。
- 需要接入两个以上核心业务系统。
- 客户没有固定业务责任人，所有反馈都由中间人转述。
- 交付时间少于 10 个有效工作日且客户不愿缩小范围。
- 客户要求无上限修改、无限培训或结果保证。
- 项目依赖尚未确认的成熟团队、第三方 API 或硬件采购。
