## 推荐使用顺序

1. 先读制度手册的商业复核结论、团队章程和验证冲刺产品说明。
2. 用能力评分表确认参与者能承担什么工作包。
3. 有企业线索时，使用首次项目启动包完成 30 分钟预审。
4. 预审通过后，复制 SOW 模板和成本测算表，完成报价评审。
5. 首支小队按 30 天计划推进，不因线索或成员数量增加而提前扩张。
6. 成熟团队参与时，单独使用联合交付协议框架和项目级 SOW。

## 共同边界

- 广西赞诺数智科技有限公司负责商务、合同、收款和项目责任。
- FDE 核心组负责现场诊断、原型验证、测试、价值测算和交付。
- 成熟团队按明确工作包提供技术、工程、架构或质量支持。
- 星火者共同体负责人才发现、实践训练和协作信用沉淀，不是合同主体、客户池、外包群或派单平台。
- 星火者会员费不保证项目、派单、收入或默认分润。
- 所有价格均为内部试运行测算，所有协议均需结合实际项目和专业意见复核。
