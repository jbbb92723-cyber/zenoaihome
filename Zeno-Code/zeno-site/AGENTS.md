## 1. 官网定位

**zenoaihome.com = Zeno 赞诺的个人品牌与商业入口。IP 枢纽 + 流量引擎。**

三个核心目标：
- **IP 建设**：展示 Zeno「传统行业 × AI 实践者」的完整画像

网站**不是**装修知识大全、AI 工具展示站。它是**一个人 + 一套判断系统 + 一个社群**的数字表达。

## 4. 技术栈

- **框架**：Next.js 14 App Router
- **部署**：Vercel（自动部署，`git push` 触发）

- **动画**：framer-motion

## 7. 视觉与文案

### 视觉方向：Zeno Studio（工坊）

> 2026-07-26 更新：从「Zeno Monastic Editorial」升级为「Zeno Studio」。
> 旧方向"修道院/画廊式编辑感"服务于装修判断系统；新方向"工坊感"服务于个人品牌枢纽——更温暖、更有能量、更"正在做事"。

**核心隐喻**：不是画廊（展品），不是工厂（流水线），是**工坊**——一个人正在做事的地方。有材料、有工具、有半成品、有真实的人。

**五条设计原则**：

| 原则 | 说明 |
|------|------|
| **工坊温度** | 温暖但不甜腻。中性底色 + 材质感。不是冷冰冰的"专业"，是有体温的"在做" |
| **星火琥珀** | 新增一个克制的高亮色（暖琥珀/星火橙），只用于 CTA、关键标记、活跃态——像工坊里唯一亮着的那盏灯 |
| **材料诚实** | 传统行业背景不用"装饰"表达——用空间、留白、质感。石头/纸张/木头的重量感，不是纹理贴图 |
| **编辑精确** | 中文排版保持高水准。但从"克制收敛"转向"自信清晰"——敢用大字、敢留白、敢说判断句 |
| **生长系统** | 网站是活的——有新文章、新项目、新成员。视觉上给人"这里在发生事情"的感觉，不是"建好了放那儿" |

**色彩**：

保留现有语义色系统（CSS 变量 `canvas` / `surface` / `ink` / `stone` / `border`），新增 **spark 强调色**：

- Canvas 基色：暖白/骨纸 `#F4F1E8` — 保留
- Ink 基色：炭黑 `#111111` — 保留
- Sand 基色：暖沙 `#DED2BE` — 保留
- **Spark 强调**：暖琥珀 — CTA 按钮 / 活跃态 / 区块标记 / 关键数字（克制的能量点）

**约束**：
- spark 只用在一屏 1-2 处，不能撒满全页
- 不形成第五个主色
- 组件边角不超过 `8px`
- 不走 SaaS 卡片风、装修公司模板风
- 动效克制（判断仪器式，非炫技）
- 移动端必须成立

### 文案
语气：**温和 · 专业 · 有判断 · 不制造焦虑 · 不油腻 · 不模板化**

禁止：千万别 / 装修小白必看 / 避坑秘籍 / 被坑惨了 / 99%的人不知道 / 一招教你 / 高端生活方式 / 松弛感拉满 / 梦中情房 / AI赋能

### 服务边界
所有服务文案必须注明：不代替签约 / 不承诺最低价 / 不制造对立 / 不替代法律审查。

## 8. 修改流程

**可直接执行**：单页文案、单组件视觉、bug 修复、数据修正、新增文章、标签调整。

**必须先审计（需 Zeno 确认）**：首页改动、导航调整、信息架构变更、目录重组、删页面/组件/数据、新增后台模型、引入新依赖、产品价格/定位变更、品牌命名变更。

## 9. 验证命令

```bash
npx.cmd tsc --noEmit      # 类型检查
npm.cmd run lint           # 代码规范
npx.cmd next build         # 构建验证
npm.cmd run build          # 完整 build（含 prisma generate）
```

> `prisma generate` 在 Windows 上可能因 Node 进程占用 DLL 而卡住——不是构建失败。
